# 跑步换装测试（V4 画风）

这是 `gen-out/run-test/` 的 V4 画风重做版。人物、骨架、8 帧冲刺循环和机位都没变，只换了画风，画风设置见 `gen-out/style-test/`：

- 卡通着色：三阶，阴影偏冷、亮面偏暖
- #3a2c22 反向外壳描边，约 3 像素
- 正前上方主光 + 背后暖色轮廓光 + AO
- 降饱和的暗土配色，头发和胡子改深棕，叠一层轻微的颗粒纹理

先按 2 倍分辨率渲染，再在预乘 alpha 下缩到 480×832。

## 和 run-test 比改了什么

1. **画风：** `scripts/style_lib.py` 是从 style-test 抽出来的画风模块。分层之前先把它套到所有部件上，镜头取景和 run-test 完全一致（ortho 2.801）。
2. **拆层方式（重要）：** run-test 是把每个部件按远/中/近侧真的切成几个网格。加了外壳描边以后，切口处会露出外壳内侧，形成一圈锯齿状的黑刺。现在改成不切网格：
   - **按面打标记：** 只给每个面打上侧别标记（颜色属性 `side_tag`）。
   - **其他侧挖空：** 渲染某一侧时，同一部件其他侧的面换成 Holdout，照样遮挡但透明。
   - **效果：** 描边始终是整个部件的真实轮廓，切口不会多出线。同一部件的几侧把像素精确地分开，叠回去就是完整的部件，不会再像以前那样各侧互相漏出来。
3. **叠层顺序：** 在 V4 图层上重新搜了一遍（从后往前）：
   `肩甲远 → 手臂远 → 上衣远 → 兜帽远 → 裤子远 → 鞋远 → 裤子中 → 裤子近 → 鞋近 → 手臂中 → 上衣中 → 头 → 兜帽中 → 兜帽近 → 手臂近 → 上衣近`

## 对齐结果（64 种搭配 × 8 帧，2D 叠层 vs 同一搭配的 3D 直出）

- **轮廓 IoU：** 平均 0.9999，最低 0.9998。
- **颜色不一致的像素：** 平均 0.78%（run-test 是 1.44%）。最好的搭配 0.29%，最差的 1.51%（ppprrr），最差单帧 2.29%。
- **差异位置：** 主要在近侧膝盖和靴筒的交界、近侧肩膀的袖口，原因是固定叠层顺序在部分搭配下前后关系不对。详见 `check/mix_metrics.md`，对比图在 `check/`。
- **骨骼位置：** 任何搭配都一样（共用骨架），头、手、脚、腰的偏差为 0 px。叠图在 `overlay/`。

## 文件

- `layers/<槽位>/<款式>/<far|mid|near>/fNN.png`：28 个可以换装的图层，按上面的顺序叠起来用。戴兜帽时，头部用 `head/hooded`（没有头发）。
- `v4_outfit_mix_dark.png`、`v4_outfit_mix_light.png`：10 种搭配同一帧的总览，分别放在暗色和浅色背景上。
- `frames/peasant/`、`frames/ranger/`：两套完整衣服的 3D 直出帧。
- `stacked/<搭配>/`：用图层叠出来的 4 种搭配。搭配编码依次是上衣、手臂、裤子、鞋、肩甲、兜帽，p=农夫，r=游侠，0=不穿。
- `preview_mix.gif`、`preview_mix.mp4`：上面 4 种搭配并排跑步。
- `overlay/`：农夫和游侠逐帧叠图，青色是农夫轮廓，洋红色是游侠轮廓。
- `check/`：3D 直出、2D 叠层和差异标记的对比图，以及 64 种搭配的误差表。
- `scripts/`：全部生成脚本。用 `split_and_render.py -- <输出目录> <帧列表> toon+outline+light+paint` 出图层，渲染后要先缩小到 1 倍，再跑 `compose.py` 和 `pack.py`。

## 不理想的地方

- **暗背景上描边不明显：** #3a2c22 描边和游戏的暗土背景太接近，人和背景主要靠背后的轮廓光分开。农夫的深棕裤子在暗背景上偏糊。
- **叠层边缘有半透明过渡：** 同一部件不同侧的分界处，两层的抗锯齿边缘叠起来会有一点点半透明过渡，误差表已经包含了这部分。
- **素材本身的局限：** 免费版只有两套衣服，没有光身版，脸和手是低多边形，跟手绘的刀客还是有差距。
