# 三套衣服的跑步换装（V4 画风）：农夫 / 游侠 / 皮甲刀客（自制）

做法和 `gen-out/run-test-v4/` 一样，只是多了一套自制的皮甲。模型和皮甲的做法见 `gen-out/model/README.md`。这里出图用的模型是肩甲修穿模之前的版本。

搭配编码依次是上衣、手臂、裤子、鞋、肩甲、兜帽：p=农夫，r=游侠，l=皮甲，0=不穿。比如 `lllll0` 是皮甲整套，`lrpr00` 是皮甲上衣 + 游侠手臂 + 农夫裤子 + 游侠靴。

## 结果

一共有 3⁵×2 = 486 种搭配，3D 参考图只渲染了其中 67 种：各套整套，加 60 种随机混搭。

- **2D 叠层 vs 3D 直出：** 轮廓 IoU 平均 0.9999，最低 0.9998。
- **颜色不一致的像素：** 平均 0.86%，最好的 0.23%（rprpl0），最差的 1.75%（lrpr00），最差单帧 2.29%。
- **叠层顺序（从后往前）：** 肩甲远 → 手臂远 → 上衣远 → 兜帽远 → 裤子远 → 鞋远 → 裤子中 → 裤子近 → 鞋近 → 手臂中 → 上衣中 → 头 → 兜帽中 → 兜帽近 → 手臂近 → 上衣近 → 肩甲近

## 文件

- `leather_outfit_mix_light.png`、`leather_outfit_mix_dark.png`：10 种搭配同一帧，分别放在浅色和暗色背景上。
- `leather_run_cycles.png`：3 套搭配的跑步循环，每行 8 帧。
- `layers/`：可以换装的图层，三套衣服 × 各槽位 × 远/中/近侧。
- `frames/peasant|ranger|leather/`：三套整套的 3D 直出帧。
- `stacked/`：用图层叠出来的 4 种搭配。
- `overlay/`：农夫整套和皮甲整套的逐帧轮廓叠图。
- `check/`：对比图和误差表。
- `preview_mix.gif`、`preview_mix.mp4`：上面 4 种搭配并排跑步。

## 不理想的地方

- **肩甲穿模：** 皮甲肩甲和兜帽或农夫上衣一起穿时会穿模，肩背处有一团毛刺状的红色，`leather_run_cycles.png` 第三行就能看到。修法见 `gen-out/model/README.md`。
- **甲片颜色偏粉：** 甲片经过 V4 降饱和后偏粉的暗红，比原画的深红淡。
- **靴子：** 还是搭扣靴，不是原画的系带长靴。
- **发型：** 没有原画的顶髻。
