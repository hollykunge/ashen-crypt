# 画风对比：同一个 8 帧冲刺循环

对象和 `gen-out/run-test/` 一样：Quaternius 模块化人物，同一副骨架，8 帧冲刺（f00–f14，按 12fps 播放就是原速）。每个变体跑两套衣服：游侠整套（`ranger` = rrrrrr），以及混搭（`mix` = 农夫上衣 + 游侠手臂 + 农夫裤子 + 游侠靴 + 游侠兜帽，即 prpr0r）。

所有变体共用同一个正交侧机位，取景和 run-test 完全一致。先按 2 倍分辨率（960×1664）渲染，再用 Lanczos 缩到 480×832，背景透明。渲染引擎是 Blender 4.5.9 EEVEE。

## 变体（逐个叠加）

| 变体 | 和上一个比改了什么 |
|---|---|
| **V0 原始** `base` | 原材质（Principled BSDF），默认的一盏太阳光加白色环境光，作参考用 |
| **V1 卡通着色** `toon` | 每个材质改成：白色 Diffuse → Shader to RGB → 亮度 → Color Ramp（常量插值，3 阶），再乘以原来的贴图底色，最后用 Emission 输出。三阶的分界点和颜色：0–0.40 冷阴影 (0.50, 0.55, 0.72)，0.40–0.68 中间调 (0.80, 0.80, 0.84)，0.68 以上暖亮面 (1.04, 0.98, 0.90)。阴影偏冷，不会出现纯黑。环境光降到 0.3：实测光照值大约分布在 0.24–0.92，这样能落进三阶。光照里不用法线贴图：用了法线贴图色阶会碎成斑点，所以用平滑的几何法线，贴图本身画的细节保留 |
| **V2 +描边** `toon_outline` | 反向外壳描边：每个部件加 Solidify（加在 Armature 之后，向外 3 像素厚，按 2 倍渲染换算成最终 3 像素，翻转法线）。描边材质用 Emission #3a2c22，并开启背面剔除。因为每个衣服部件是独立的网格，袖口、腰带、膝盖和靴筒的交界处也会出线，内侧轮廓就有了。眼睛和眉毛不描边，头发的线细一点（×0.6）。没用 Line Art：外壳法在 2 倍超采样下线条够干净，而且每个部件可以独立开关，和分层出图对得上 |
| **V3 +三点光/AO** `toon_outline_light` | 主光改到正前上方（镜头这一侧，人物前方，仰角 40°）。加一盏背后轮廓光：从人物背后偏上照过来，暖色，强度 2.0。轮廓高光只在边缘出现，而且只在朝向轮廓光的那一面：用视角朝向比（Layer Weight > 0.62）× 法线朝向（法线 · 轮廓光方向 > 0.45）来限定，再用滤色叠一层暖色，强度 0.25。AO 节点（距离 0.12）压到 0.45–1 的范围，乘进光照值，再进色阶，所以夹缝处会落进阴影那一阶 |
| **V4 +笔触/暗土配色** `toon_outline_light_paint` | 底色先降饱和（×0.72）、压暗（×0.86），再往暖棕 #6b523c 拉 14%。头发和胡子改成深棕 #2e2018，保留 35% 的原贴图发丝明暗。再叠一层各向异性噪点（物体空间，缩放 90/90/18，明暗在 0.86–1.10 之间浮动），像笔触或纸纹；它是贴在布料上的，跑动时不会“游动” |

## 文件

- `compare_f04_light.png`、`compare_f04_dark.png`：同一帧（f04）的并排对比，每个变体一列，上行游侠整套，下行混搭。分别放在浅色（#d9d2c5）和游戏的暗土色（#2a221c）背景上。
- `compare_f10_light.png`、`compare_f10_dark.png`：同样的对比，换成另一个姿势（f10）。
- `video/<变体>.mp4`：每个变体的跑步视频，游侠整套和混搭并排，12fps，循环 6 遍。
- `frames/<变体>/<ranger|mix>/fNN.png`：480×832 透明背景的单帧。
- `scripts/`：`style.py`（变体开关可以组合，例如 `toon+outline+light+paint`）、`pack_style.py`、`probe_light.py`（用来测光照值范围）。

## 推荐：V4（卡通着色 + 描边 + 三点光/AO + 笔触/暗土配色）

- **最不像默认光照的 3D：** 大块明暗分阶，阴影偏冷不发黑，再加墨色线和暗土色调，体积感有了，塑料感也基本没了。
- **最贴游戏的色调：** 放在暗色背景上，只有 V4 的配色能融进游戏原来的土色调。V0–V3 的绿色太艳，在暗背景上很跳。
- **轮廓光很关键：** 放在暗背景上时，#3a2c22 的墨线几乎看不见（和背景太接近），这时候靠 V3/V4 的背后轮廓光把人从背景里分出来。所以描边和轮廓光要一起用。

## 不理想的地方

- **离手绘还有距离：** 底下还是低多边形模型，脸部细节少，手是方块状的，跟原来手绘的刀客比还是差得远。
- **描边在暗背景上不明显：** 如果游戏场景整体很暗，可以考虑把描边颜色调亮一点，或者改成随背景变化。
- **笔触纹理偏弱：** 噪点是程序生成的，算不上真正的笔触；缩到 480×832 以后只剩一点轻微的颗粒感。要更像手绘，得换一张真实的笔刷或纸纹贴图。
- **还没接回分层出图：** 这些变体是整个人直接 3D 渲染的，还没有像 run-test 那样按装备槽拆层。选定画风后，把同样的材质设置接到 `split_and_render.py` 上重出图层就行。不过外壳描边会让部件交界处的线在混搭时叠两层，需要再验证一遍。
