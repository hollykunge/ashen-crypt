# 跑步换装测试：3D 部件 → 2D 分层精灵

目标：做一套 6–8 帧的跑步动画，衣服按装备槽（上衣、手臂、裤子、鞋、肩甲、兜帽）独立换装、随意混搭，每帧轮廓都要对齐。

最初的方案是用视频模型（Wan 2.2 I2V + Animate）生成刀客动画。中途改了方向：不再用刀客，人物随便，只要能随意换装。所以改成用免费的 3D 模块化人物在 Blender 里渲染，分层输出 2D 帧。视频模型那条线没跑：ComfyUI 已经装好，模型只下了一部分，下载暂停了。

## 用到的素材（全部 CC0，可商用、不用署名）

| 素材 | 版本 | 用途 |
|---|---|---|
| [Quaternius Modular Character Outfits – Fantasy](https://quaternius.itch.io/modular-character-outfits-fantasy) | 免费 Standard 版 v2.1 | 衣服部件。免费版只有 Peasant（农夫）和 Ranger（游侠）两套男装 |
| [Quaternius Universal Base Characters](https://quaternius.itch.io/universal-base-characters) | 免费 Standard 版 | 只取头部（脸、眼睛、眉毛），加上发型和胡子 |
| [Quaternius Universal Animation Library](https://quaternius.itch.io/universal-animation-library) | 免费 Standard 版（不带根运动） | `Sprint_Loop` 冲刺循环 |
| Blender 4.5.9 LTS | 便携版 | 组装和渲染 |

三套素材共用同一套 65 根骨骼（骨骼名一致），所有部件绑在同一副骨架上，所以**每一帧的骨骼位置在任何搭配下都完全相同**。

## 做法

1. **组装** `scripts/build_scene.py`：以衣服部件的骨架为主骨架，把两套衣服的所有部件、底模的头部（按头/颈骨骼权重切出来）和发型都挂上去，套 `Sprint_Loop` 动作。
2. **拆层并渲染** `scripts/split_and_render.py`：
   - **拆近、中、远侧：** 每个部件按骨骼权重拆成远侧（左半身，`_l` 骨骼）、中间、近侧（右半身，`_r` 骨骼）。
   - **出图层：** 按「槽位 × 款式 × 侧」各渲染一层，共 28 个图层。
   - **渲染参数：** 固定正交侧机位，人物朝右。分辨率 480×832，背景透明，EEVEE 渲染，关掉部件之间的投影。
   - **取帧：** 从 16 帧的循环里每隔一帧取一帧（f00, f02 … f14），共 8 帧。原动作 24fps，所以这 8 帧按 12fps 播放就是原速。
   - **3D 参考：** 同时把 64 种搭配（2⁶）直接用 3D 各渲染一遍，作为对照。
3. **叠层顺序** `scripts/compose.py`：用贪心插入法，在 64 种搭配 × 8 帧上找平均误差最小的固定叠层顺序（从后往前）：
   `肩甲远 → 手臂远 → 上衣远 → 兜帽远 → 裤子远 → 鞋远 → 裤子近 → 裤子中 → 鞋近 → 手臂中 → 上衣中 → 头 → 兜帽中 → 兜帽近 → 手臂近 → 上衣近`
4. **打包** `scripts/pack.py`。脚本里的路径是本机路径（`D:\quaternius`、`D:\blender-4.5.9-windows-x64`），换机器要改。

## 对齐结果

- **两套衣服直接对比（叠图在 `overlay/`）：** 头、手、脚、腰的位置完全一致（共用骨骼，偏差 0 px）。轮廓只差衣服本身的厚度，比如兜帽和靴筒。
- **换装后的 2D 叠层 vs 同一搭配的 3D 直出：** 64 种搭配 × 8 帧全部比过。详见 `check/mix_metrics.md`。
  - **轮廓 IoU：** 平均 0.9999，最低 0.9998，即轮廓逐像素对齐。
  - **颜色不一致的像素：** 平均 1.44%。最好的搭配 0.39%，最差的 2.85%，最差单帧 3.49%。

## 不理想的地方

- **叠层顺序固定：** 部件交叠处（近侧肩膀袖口、近侧膝盖与靴筒）在部分搭配下前后关系不对，`check/` 里用洋红色标出。例如 Ranger 上衣配 Peasant 手臂时，Ranger 的袖口压在了 Peasant 袖子上。能改进的办法：把这几处再细拆成更小的图层，或者针对具体搭配另出遮罩。
- **只有两套衣服：** 免费版只有 2 套男装；12 套全款要付费买 Source 版。
- **没有光身版：** 免费底模只有「Superhero」体型，比例和衣服的「Regular」体型不一样，所以只用了它的头，至少要穿一件衣服。头发是灰白色的。
- **肩甲只有一个，在左肩：** 左肩是远侧，所以大部分时候被身体挡住，只露出一点灰色金属。
- **画风：** 低多边形 3D 卡通风，光照比较平，没有描边，跟原来手绘刀客的画风差别很大。

## 文件

- `layers/<槽位>/<款式>/<far|mid|near>/fNN.png`：可以换装的图层，游戏里按上面的顺序叠起来用。`head/hooded` 是戴兜帽时用的无头发版本。
- `frames/peasant/`、`frames/ranger/`：两套完整衣服的 3D 直出帧（参考用）。
- `stacked/<搭配>/`：用图层叠出来的 4 种搭配。搭配编码依次是上衣、手臂、裤子、鞋、肩甲、兜帽，p=Peasant，r=Ranger，0=不穿。
- `overlay/`：农夫和游侠逐帧叠图，青色是农夫轮廓，洋红色是游侠轮廓。
- `check/`：3D 直出 / 2D 叠层 / 差异标记 对比图，以及 64 种搭配的误差表。
- `preview_mix.gif`、`preview_mix.mp4`：4 种搭配并排跑步。
- `frames_sheet.png`：两套完整衣服的 8 帧总览。
- `scripts/`：全部生成脚本。
