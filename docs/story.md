# 余烬地牢 · 叙事与两阶段结构

主角是凡人，为救家人与世间疾苦而求仙。他要完成仙界立下的**规矩**与**劫数**。

**但成仙是骗局** —— 是仙界给人间画的大饼，是清除异己的手段。最后主角杀尽众仙、回归家庭。珍惜眼前、陪家人过好每一天，才是人间真谛。

| 阶段 | 内容 | 现在做吗 |
| --- | --- | --- |
| **第一阶段** | 成仙之路：一甲子、五境界、五劫、五规矩 | **做** |
| 第二阶段 | 发现骗局、杀尽众仙、回归家庭 | 不做，但要为它留好接口 |

---

## 0. 一个判断：伏笔不用新做，已经在那里了

这份premise最关键的一点是 —— **前面四份文档里已经写好的系统，几乎全是现成的伏笔。** 它们当初是作为"优雅的平衡设计"写的，换一个视角看，每一条都是骗局的证据。

| 已有机制 | 第一阶段的表面含义 | 第二阶段揭穿后的含义 |
| --- | --- | --- |
| **四条守恒律，和全是定值**（[成仙 §5](ascension.md#5-四条守恒律)） | 优雅的平衡 | **局是做平的。** 任何选择期望完全相同 —— 庄家从不亏 |
| **克劫之行必处囚位**（[成仙 §3.1](ascension.md#31-克劫之行必然处囚位)） | 渡劫本该艰难 | 考核从结构上就被做空：它不想让你过 |
| **天劫强制改变当令**（[成仙 §3](ascension.md#3-天劫五道关卡)） | 天劫声势浩大 | 仙界能推翻它自称的天道，你不能 |
| **忌神装备差 2.5~3.3 倍**（[命格 §3](bazi-destiny.md#3-契合度八字如何改变装备)） | 命格决定适配 | 仙界替你决定了你能用什么 |
| **喂养：生它反而给它回血**（[世界 §4.3](wuxing-world.md#43-喂养整套设计里最重要的一条)） | 五行的道理 | 顺从者反哺体制 |
| **转世宿慧上限 +10%**（[成仙 §4](ascension.md#4-转世失败与重选命格的正规途径)） | 失败的地板 | 回收失败者，且不许你真的成长 |
| **列仙图录** | 你要加入的仙班 | **击杀名单** |
| **伏山兽**（"降伏失控的镇山兽"，已在代码里） | 第一个 Boss | **上一个渡劫失败者** |
| **土地公 / 灶君** | 引路人 | 同样被困的底层小神 —— 第二阶段的盟友 |
| **太上老君 / 西王母** | 高阶考官 | 骗局的设计者 |

**一行新系统都不用加。** 第一阶段只要把这些照直做出来、不眨眼、不暗示，第二阶段的反转就自己成立了。

> 其中最该珍惜的是**伏山兽**：它已经在 [combat.gd](../mobile/scripts/combat.gd) 里，是玩家第一场硬仗。让它在第一阶段只是"失控的镇山兽"，到第二阶段才揭穿它是谁 —— 玩家会想起自己开局就杀了一个和自己一样的人。

## 1. 一层就是一年，一个甲子就是一生

这是第一阶段的情感引擎，而它完全来自已有的设定：**一层 = 一个流年 = 一年**。

所以 **一甲子 = 60 层 = 60 年 = 主角的一辈子**。第一阶段就是一甲子。

主角 20 岁入道，一层一年（已验算）：

| 层/年 | 主角 | 事件 | 家人 |
| --- | --- | --- | --- |
| 0 | 20 | 入道 | 父 48 母 45 妻 19 弟 10 |
| 3 | 23 | 长女出生 | 父 51 母 48 妻 22 弟 13 女 0 |
| **10** | 30 | **木劫 · 炼气成** | 父 58 母 55 妻 29 弟 20 女 7 |
| 18 | 38 | **父亡（66）** | 母 63 妻 37 弟 28 女 15 |
| **20** | 40 | **火劫 · 筑基成** | 母 65 妻 39 弟 30 女 17 |
| 26 | 46 | **母亡（71）** | 妻 45 弟 36 女 23 |
| **30** | 50 | **土劫 · 结丹成** | 妻 49 弟 40 女 27 |
| 35 | 55 | **弟亡（45，矿难）** | 妻 54 女 32 |
| **40** | 60 | **金劫 · 炼神成** | 妻 59 女 37 |
| 44 | 64 | **妻亡（63）** | 女 41 |
| **50** | 70 | **水劫 · 还虚成** | 女 47，外孙出生 |
| **60** | 80 | **待诏期满 —— 仙界命你断绝尘缘** | 女 57 |

拿到第一个境界时（层 10），你要救的人还都活着。到还虚（层 50），除长女外一个不剩。

**而你自己的阳寿一路在涨。**

| 层 | 年龄 | 阳寿上限 |
| --- | --- | --- |
| 0 | 20 | 70（凡人） |
| 10 | 30 | 90 |
| 30 | 50 | 130 |
| 50 | 70 | 170 |

每成一个境界 +20 年阳寿 —— **只给你，不给家人**。而[规矩](#2-五条规矩)第二条恰好是「不得延凡人之寿」。

> **你为救他们而求的东西，正是让你活过他们的东西。** 这句话不用台词讲，表格自己会讲。

### 1.1 家不是过场动画，是一个真实选项

每一层玩家都可以选择**回家待一年**而不是下一层。回家给的是实打实的好处 —— 回复、下一层的减益豁免、长女带来的材料、[随侍](origins.md#2-官宦随侍与命运)的士气 —— 但那一年的层数不前进，而家人照常变老。

**回家必须真的划算**，否则这个选择是假的，玩家只会觉得被道德绑架。划算了，这个选择才成立：你是真的在"值得的事"之间做取舍。

第二阶段揭穿骗局后，玩家会发现：**唯一没有被做平期望的，就是在家里的那些年。**

## 2. 五条规矩

仙界立的规矩，一个境界解锁一条。每条都是**真约束**，也都**可以违反**。

| 境界 | 规矩 | 违反的代价 |
| --- | --- | --- |
| 炼气 | **不得以仙法济凡人** —— 修行所得不可换作凡俗救济 | 境界 −1 |
| 筑基 | **不得延凡人之寿** —— 阳寿不可转赠 | 境界 −1，下一劫门槛 +0.10 |
| 结丹 | **不得泄露天机** —— 不可教凡人修行之法 | 境界 −1 |
| 炼神 | **不得抗敕** —— 敕令不可拒 | 敕令改派更重者 |
| 还虚 | **断绝尘缘** —— 成仙前须自断牵挂 | 不断则不得成仙 |

五条读下来像戒律，回头看是**锁**：前三条锁死"修行者不能帮凡人"，第四条锁死"不能说不"，第五条锁死"不能有人"。

**第五条是第一阶段的终点。** 你为家人走了六十年，最后仙界要你先把家人划掉。

### 2.1 违规要能真的做

玩家应当**可以**在第 18 层用仙法救父亲、在第 35 层把阳寿转给弟弟。代价明确（境界 −1，等于白修十年），但这是玩家自己的选择。

能违规，这个主题才是**玩出来的**，不是被讲出来的。而每一次违规都会被记下来（§4），第二阶段会用到。

## 3. 第一阶段的边界

### 3.1 做什么

- 一甲子 60 层、六个大运、五境界、五劫（[成仙主线](ascension.md)）
- 五条规矩，可守可犯
- 家人时间线与「回家」选项
- 敕令：土地公起步，随境界升格到灶君、青鸟使者、西王母、太上老君
- 伏山兽作为第一场硬仗，**不揭穿它是什么**

### 3.2 绝不做什么

- **不揭穿骗局。** 不暗示、不眨眼、不留"聪明的台词"。伏笔靠机制（§0）和表格（§1）自己起作用，玩家只有回头看才读得懂。
- **不埋需要立刻回答的悬念。** 第一阶段结束时玩家可以觉得"不对劲"，但不能觉得"没讲完"。
- **不做第二阶段的任何战斗内容。** 六位仙人不做 Boss 战。

### 3.3 怎么收尾：两个结局

第 60 层待诏期满，仙界命你断绝尘缘。这是第一阶段的最后一个选择，也是它唯一需要的结局设计。

| 选择 | 结局 | 收尾 |
| --- | --- | --- |
| **断** | **上界** —— 你在列仙图录上占一席 | 最后一镜：你的席位，然后是空了的屋子；长女在坟前烧纸，碑上两个名字，一个是你 |
| **不断** | **留** —— 不得成仙，留在凡间 | 短、暖、刻意"不完整"：你回家，长女还在，外孙七岁 |

**两个结局都是完整的，都不是悬崖。** 「上界」留下一股说不出的不对劲；「留」看起来像是没打完的遗憾结局 —— 而第二阶段会证明它才是对的。

> 这是整个方案里最重要的一个决定：**第一阶段必须独立成立。** 如果它的满足感依赖第二阶段兑现，而第二阶段没做出来（或做晚了），整个游戏就塌了。两个结局让它自己站得住。

## 4. 第二阶段要用的数据，现在就得存

这是最关键的一条工程提醒：**第一阶段必须把玩家的选择记下来，哪怕现在不用。** 这些数据现在写一行就有，以后再也补不回来。

```gdscript
# 存档里的叙事记录，第一阶段只写不读
{
  "rules_broken": {                 # 每条规矩违反的层数列表
    "no_aid":    [18],              # 第 18 层用仙法救了父亲
    "no_lifespan": [],
    "no_teach":  [],
    "no_refuse": [22, 41],
    "sever":     false              # 最终是否断绝尘缘
  },
  "years_at_home": 7,               # 累计回家的层数
  "deathbed_present": {             # 家人亡故时主角是否在身边
    "father": true, "mother": false, "wife": false, "brother": false
  },
  "edicts_refused": [22, 41],
  "beast_spared": false,            # 伏山兽：降伏还是放走
  "ending": "ascend"                # ascend / stay
}
```

第二阶段会用它们决定：哪位小神愿意站你这边、你杀仙时的力量来源、长女还认不认你、最后的家还在不在。

**第一阶段不读这些字段，只写。** 不要为了"让玩家现在就看到效果"而提前消费它们 —— 那会破坏 §3.2。

## 5. 要改的既有判断

### 5.1 不要删 `combat.gd::HEROES`

我在[命格 §6.1](bazi-destiny.md#61-要删的) 里写过"拆掉 `HEROES` 三职业"。**那条建议要修正。**

现在那三套（神将 / 神射 / 雷法）连技能带数值都在代码里 —— 镇山诀、连珠箭、五雷印。第二阶段要杀的正是这六位仙人，**这三套就是他们的招式模板**。

所以：**从玩家可选项里摘出来，但当作仙人 Boss 的数据留着。** 不是删除，是搬家。

### 5.2 成仙之路从五甲子压到一甲子

我原先写的是"五甲子 300 层成仙"。新前提下**一甲子 60 层**才对：

- **一甲子 = 一生**，这是主题本身要求的长度
- 五境界、五劫全部装进一个甲子（劫在第 10/20/30/40/50 层），五行覆盖不变
- 第一阶段落到 6~10 小时，是一个能真正做完的范围

300 层那个版本是在没有叙事前提时定的，现在它既不对味也不该做。

## 6. 风险

### 6.1 最大的风险：反转会不会背叛玩家，而不只是背叛主角

"你修了一辈子，全是假的"——这是叙事反转最经典的翻车点。玩家会觉得被耍的不是主角，是自己。

**对策只有一条，而且必须写进设计铁律：**

> **骗局骗的是承诺，不是力量。** 第二阶段不清空任何东西 —— 装备、境界、阳寿、随侍全部保留，并且正是用它们去杀仙。

玩家六十年的投入在第二阶段**变成武器**。被辜负的是主角的期待，不是玩家的存档。这条一旦破了（比如"成仙后发现修为是假的、要重新开始"），整个双阶段结构就是在惩罚玩家。

### 6.2 其他

1. **第一阶段不能苦。** 主题是沉重的，但 60 层的过程必须好玩 —— 打怪、掉材料、炉坊里折腾五行配比，这些乐趣要撑住全程。悲剧是底色，不是玩法。
2. **家人不要做成催债的。** 不要有"你已经 3 年没回家了"这种提示。家人的状态客观呈现（年龄、健康、来信），不评判。让玩家自己难受，比让 UI 指责他有效得多。
3. **回家必须真划算**（§1.1）。否则这个选择是假的。
4. **规矩的违反代价要狠但要值。** 境界 −1 等于白修十年 —— 玩家应该在"救父亲"和"十年修行"之间真正犹豫。如果代价太轻，守规矩就没有重量；太重则没人敢违反，那条机制等于不存在。
5. **"留"的结局不要做成 Bad Ending。** 不要灰屏、不要"你放弃了"。它要暖、要短、要让人心里一动 —— 它是真谛的预告。给成就，但别给负面评价。
6. **六位仙人在第一阶段要立住性格。** 第二阶段要杀他们，玩家得先认识他们。每位至少主持一次天劫或派一道敕令，有自己的语气和立场 —— 其中应当有一两位让玩家觉得"他好像也不情愿"。
7. **土地公和灶君要留住好感。** 他们是住在人间的小神（灶君就在灶台边），第二阶段的盟友。第一阶段不要把他们写成帮凶。
