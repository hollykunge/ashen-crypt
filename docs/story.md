# 吾行 · 叙事主线

主角是个凡人。他看见人间疾苦 —— 旱、涝、疫、矿难、流民 —— 凡人的手够不着，所以他去求仙。他要的从来不是长生，是**力量够大到能救人**。

他守仙界立的**规矩**，渡仙界设的**劫数**，一路从村口土地公的杂役爬到待诏仙班。

**而人间的疾苦，正是仙界做出来的。** 旱涝疫疠是上界派下的劫数配额：人间越苦，求仙的人越多，仙界才有源源不断的候补可筛、可用、可清除。他求了一辈子的那个班次，就是害人的那个班次。

于是**屠仙**。

| 幕 | 层 | 内容 |
| --- | --- | --- |
| **第一幕** | 1–50 | 成仙之路：五境界、五劫、五规矩。你一次次发现自己救不了人 |
| **转折** | 51–60 | 待诏期。证据凑齐，真相揭开 |
| **第二幕** | 61+ | 屠仙。列仙图录从"要加入的仙班"变成**击杀名单** |

---

## 0. 一句话

> **他为救人而成仙，成了仙才知道人是仙害的。**

这句话决定了全部设计。它只需要两件事成立：

1. **第一幕必须让玩家真的想救人，并且真的救不了。** 不是台词说救不了，是规矩逐条拦住他。
2. **真相揭开时，玩家六十层的投入不能被清空。** 它要原封不动地变成屠仙的武器（§7 铁律一）。

这里**没有年龄、没有阳寿、没有大运流年**。层数就是层数，世界的轮转由[地气](wuxing-world.md#5-山门地气与十层一轮)管，十层一轮。时间不是这个故事的主题 —— **人间的苦是谁造的**才是。

---

## 1. 两幕结构

### 1.1 第一幕：1–50 层

[五境界五劫](ascension.md)，十层一境界。每个境界解锁一条[规矩](#2-第一幕你救不了人)。

每一层是一个地方 —— 旱村、疫城、铁矿、决口的河堤 —— 和一道敕令。敕令的表面内容是"清山门、护灶火、守丹台、开云路、伏山兽"这类仙界杂役，而**你脚下那个地方正在死人**。两件事同时摆在屏幕上，但敕令从不提它。

### 1.2 驻留行善：一个真实选项

每一层玩家都可以选择**驻留本层**而不是进下一层，把修行所得用在这个地方：赈灾、治疫、撑梁救矿、收殓战殁、修堤塞决。

驻留给的是实打实的好处，但那一层的进度不前进：

| 收益 | 量 |
| --- | --- |
| 本地人送材料 | 本层地气同干材料 ×4（通关一层只给 ×3），**外加一件该地域的 T3** |
| 下一层蒙荫 | 下一层所有装备的**死位按囚位计**（`q` 0.75 → 0.85） |
| 随侍士气 | 官宦下一层随侍数 +1（上限仍是 3） |

T3 是那件要紧的东西 —— 高阶材料平时只能靠刷，这是唯一能稳定拿到的途径。

> **不要把"回满生命"算成收益。** 进层与挂机本来就满血开（`combat.gd::reset()`），写进收益表只是自欺。

**驻留必须真的划算**，否则这个选择是假的，玩家只会觉得被道德绑架。划算了，它才成立：你是真的在"变强"和"救人"之间做取舍。

每十层那一层（天劫层：焦原、焰顶山、沉山、刃岭、沉渊）**没有行善这个选项** —— 那里已经是灾的终局，救不回来了。

> 而第一条规矩（§2）恰好写着**不得以仙法济凡人**。所以**渡过木劫之后**，驻留行善就是**违规行为**（第 11 层起；第 10 层本身是木劫，规矩要到渡完劫才立）。这是整个第一幕最关键的一处咬合：游戏先教会玩家救人是值得的，再立规矩禁止它。
>
> 代价是真的：境界 −1 会**退一档炉温上限**，等于白修十层。

### 1.3 转折：51–60 层待诏期

五气俱足，等仙界开门。这十层不再有天劫，敕令也变了性质 —— 你开始替上界**办事**而不是跑腿：

| 层 | 你被派去做的事 | 你看见的 |
| --- | --- | --- |
| 51–53 | 核验某郡的"劫数账目" | 旱三年、亡七千，数目是**预先定下的** |
| 54–56 | 押送一名抗敕的修行者 | 他说的话和你第 30 层想过的一样 |
| 57–59 | 为一场即将降下的疫劫"开云路" | 你亲手给它放了路 |
| 60 | 受箓前的最后一条规矩：**尽忘人间** | 仙界要你把救过的人全部忘掉 |

真相不靠一段独白揭开，靠**账目**：你自己做过的五十层敕令，在待诏期被一条条对上账。玩家会先于主角反应过来。

### 1.4 第二幕：61 层起，屠仙

第 60 层的最后一条规矩是**尽忘人间**。玩家在这里做第一幕唯一需要的那个选择，两条路都进第二幕：

| 选择 | 第二幕的起点 |
| --- | --- |
| **受箓** | 你答应了，领了仙箓上界。**从里面动手** —— 你有仙班的身份、能进他们的殿、能看他们的账 |
| **抗敕** | 你当场拒了，被打落人间。**从底下起兵** —— 你没有身份，但人间认得你，土地公和灶君也认得你 |

两条路的内容不同，难度相当，都不是惩罚。受箓多一层"你曾经是他们的一员"的重量，抗敕多一层"你什么都没有"的重量。

## 2. 第一幕：你救不了人

仙界立五条规矩，一个境界解锁一条。每条都是**真约束**，也都**可以违反**。

| 境界 | 规矩 | 它真正锁住的 | 违反的代价 |
| --- | --- | --- | --- |
| 炼气 | **不得以仙法济凡人** | 修行所得不可换作凡俗救济 | 境界 −1 |
| 筑基 | **不得逆天灾** | 旱、涝、疫是天数，不可平 | 境界 −1，下一劫门槛 +0.10 |
| 结丹 | **不得泄露天机** | 不可教凡人修行之法 —— 他们只能等人来救 | 境界 −1 |
| 炼神 | **不得抗敕** | 敕令不可拒 | 敕令改派更重者 |
| 还虚 | **尽忘人间** | 成仙前须自断对人间的牵挂 | 不断则不得成仙 |

五条读下来像戒律，回头看是**锁**：前三条锁死"修行者不能帮凡人"，第四条锁死"不能说不"，第五条锁死"不能记得"。

**第二条是整套规矩的心脏。** "天灾是天数"这句话在第一幕是一条规矩，在第二幕是一句**供词** —— 天数是他们定的。

### 2.1 违规要能真的做

玩家应当**可以**在第 12 层开仓赈灾、在第 23 层把炼气法门写给矿工、在第 41 层抗掉一道"为疫劫开云路"的敕令。代价明确（境界 −1，等于白修十层），但这是玩家自己的选择。

能违规，这个主题才是**玩出来的**，不是被讲出来的。而每一次违规都会被记下来（§6），第二幕会用到。

### 2.2 代价要狠但要值

境界 −1 等于白修十层。玩家应该在"救这个郡"和"十层修行"之间真正犹豫。太轻则守规矩没有重量，太重则没人敢违反，那条机制等于不存在。

## 3. 伏笔早就在系统里

这份前提最关键的一点：**前面四份文档里已经写好的系统，几乎全是现成的伏笔。** 它们当初是作为"优雅的平衡设计"写的，换一个视角看，每一条都是证据。

| 已有机制 | 第一幕的表面含义 | 第二幕揭穿后的含义 |
| --- | --- | --- |
| **四条守恒律，和全是定值**（[成仙 §5](ascension.md#5-四条守恒律)） | 优雅的平衡 | **局是做平的。** 任何选择期望完全相同 —— 庄家从不亏 |
| **克劫之行必处囚位**（[成仙 §3.1](ascension.md#31-克劫之行必然处囚位)） | 渡劫本该艰难 | 考核从结构上就被做空：它不想让你过 |
| **天劫强制改变当令**（[成仙 §3](ascension.md#3-天劫五道关卡)） | 天劫声势浩大 | 仙界能推翻它自称的天道，你不能 |
| **忌神装备差 2.5~3.3 倍**（[命格 §3](bazi-destiny.md#3-契合度命格如何改变装备)） | 命格决定适配 | 仙界替你决定了你能用什么 |
| **喂养：生它反而给它回血**（[世界 §4.3](wuxing-world.md#43-喂养整套设计里最重要的一条)） | 五行的道理 | 顺从者反哺体制 |
| **转世宿慧上限 +10%**（[成仙 §4](ascension.md#4-转世失败与重选命格的正规途径)） | 失败的地板 | 回收失败者，且不许你真的成长 |
| **列仙图录** | 你要加入的仙班 | **击杀名单** |
| **伏山兽**（"降伏失控的镇山兽"，已在代码里） | 第一场硬仗 | **上一个渡劫失败者** |
| **土地公 / 灶君** | 引路人 | 同样被困的底层小神 —— 第二幕的盟友 |
| **太上老君 / 西王母** | 高阶考官 | 这套配额的设计者 |

**一行新系统都不用加。** 第一幕只要把这些照直做出来、不眨眼、不暗示，转折就自己成立了。

> 其中最该珍惜的是**伏山兽**：它已经在 [combat.gd](../mobile/scripts/combat.gd) 里，是玩家第一场硬仗。让它在第一幕只是"失控的镇山兽"，到第二幕才揭穿它是谁 —— 玩家会想起自己开局就杀了一个和自己一样的人。

### 3.1 第一幕不许眨眼

- **不提前揭穿。** 不暗示、不留"聪明的台词"。伏笔靠机制和账目自己起作用。
- **不埋需要立刻回答的悬念。** 第一幕的每一层都要能自己收尾。
- **人间的苦客观呈现，不评判。** 不要有"你已经三层没救人了"这种提示。让玩家自己难受，比让 UI 指责他有效得多。

## 4. 转折：待诏期与真相

真相有三层，一层比一层具体：

| 层次 | 内容 | 玩家怎么知道 |
| --- | --- | --- |
| **一** | 天灾不是天数，是派下来的 | 第 51 层的劫数账目：亡数是**预定**的 |
| **二** | 派它的目的是筛人 | 账目另一栏：这个郡该出几个修行者 |
| **三** | 你自己一直在替它办事 | 把你五十层的敕令和账目对上 —— 一条不差 |

第三层是关键。**玩家不是被告知真相，是被对账单证明自己是共犯。** 这件事只有第一幕老老实实让玩家做满五十道敕令才可能成立。

而这里有一个必须守住的分寸：**玩家的愤怒要朝向仙界，不能朝向设计者。** 对策见 §7 铁律一。

## 5. 第二幕：屠仙

### 5.1 列仙图录即击杀名单

六位仙人（二郎神、九天玄女、后羿、青鸟仙子、雷部天师、电母）在第一幕是图鉴和考官，在第二幕是 Boss。

[combat.gd](../mobile/scripts/combat.gd) 里的神将 / 神射 / 雷法 三套（镇山诀、连珠箭、五雷印）连技能带数值都在，**它们就是这些仙人的招式模板**。所以第二幕的战斗数据是现成的 —— 从玩家可选项里摘出来当 Boss 数据用，不是删除，是搬家（[成仙 §6.1](ascension.md#61-要改的)）。

**每位仙人在第一幕必须立住性格**：至少主持一次天劫或派一道敕令，有自己的语气和立场。其中应当有一两位让玩家觉得"他好像也不情愿" —— 第二幕他们可以倒向你。

### 5.2 盟友：被困在底下的小神

土地公住在村口，灶君就在灶台边。他们和凡人一样被这套配额压着，只是多知道一点内情。

**第一幕不要把他们写成帮凶。** 他们派给你的是真杂役，不是害人的活；偶尔有一句说不下去的话。第二幕他们是第一批站你这边的人。

### 5.3 力量从哪来

不是新的修炼体系。第二幕的力量来源有三条，全部来自第一幕的存档（§6）：

| 来源 | 取决于 |
| --- | --- |
| **你的修为** | 境界、装备、[炉温](crafting-rules.md)、随侍 —— 原封不动全部保留 |
| **人间认你** | 你驻留行善过的层、你违规救下的人 |
| **小神倒戈** | 你没有把他们当帮凶对待、你抗过的敕令 |

第三条是最该做出来的一条：**玩家守规矩越狠，第二幕的盟友越少。** 守规矩不是错 —— 它换来的是更高的境界。两条路都能打，代价不同。

## 6. 要存的叙事记录

**第一幕必须把玩家的选择记下来，哪怕现在不用。** 这些数据现在写一行就有，以后再也补不回来。[realm.gd](../mobile/scripts/rules/realm.gd) 的 `_new_narrative()` 已经是这个形状：

```gdscript
{
  "rules_broken": {                 # 每条规矩违反的层数列表
    "no_aid":      [12],            # 第 12 层开仓赈灾
    "no_calamity": [],
    "no_teach":    [23],            # 第 23 层把法门写给矿工
    "no_refuse":   [41],
    "sever":       false            # 最终是否尽忘人间
  },
  "aided_layers": [12, 19, 23],     # 驻留行善的层
  "mortals_saved": 3,               # 救下的地方（个数）
  "mortals_lost": 11,               # 路过而没救的那些地方的待救人数之和
  "edicts_refused": [41],
  "beast_spared": false,            # 伏山兽：降伏还是放走
  "act_one_ending": "accept"        # accept（受箓）/ defy（抗敕）
}
```

第二幕用它们决定：哪位小神愿意站你这边、人间认不认你、六位仙人里谁可以倒戈、最后的结局。

存档另有两个字段承载规矩的代价，和叙事记录分开放在角色上：`realm_offset`（境界欠账，≤ 0，境界一律由层数加它现算）与 `jie_threshold_bonus`（「不得逆天灾」抬高的下一劫门槛 —— **目前只写不读**，因为渡劫门槛本身还没在战斗里生效）。

**第一幕只写不读。** 不要为了"让玩家现在就看到效果"而提前消费它们 —— 那会破坏 §3.1。

## 7. 设计铁律

### 铁律一：骗局骗的是承诺，不是力量

"你修了一辈子，全是假的"——这是叙事反转最经典的翻车点。玩家会觉得被耍的不是主角，是自己。

> **第二幕不清空任何东西。** 装备、境界、材料、随侍、炉温全部保留，并且正是用它们去杀仙。

被辜负的是主角的期待，不是玩家的存档。这条一旦破了（比如"成仙后发现修为是假的、要重新开始"），整个双幕结构就是在惩罚玩家。

### 铁律二：第一幕不能苦

主题是沉重的，但 60 层的过程必须好玩 —— 打怪、掉材料、炉坊里折腾五行配比，这些乐趣要撑住全程。悲剧是底色，不是玩法。

### 铁律三：第一幕要能独立成立

如果第一幕的满足感依赖第二幕兑现，而第二幕做晚了，整个游戏就塌了。所以第 60 层的两个选择各自都是**完整的一个收束**：受箓是"你成了"，抗敕是"你不干了"。第二幕从它们任何一个往下接，而不是从一个悬崖往下接。

## 8. 风险

1. **"你是共犯"这件事要给得准。** §4 第三层真相是全作最有力的一击，也最容易变成羞辱玩家。对账单要客观 —— 列敕令、列账目、不下判语。玩家自己会得出结论。
2. **第一条规矩禁的正是第一幕教的事**（§1.2）。这个咬合是故意的，但必须让玩家**看得见代价再选**：驻留行善的违规提示要在确认前明确写出"境界 −1"。因为**不知道**而失去十层修行，是最糟的体验。
3. **驻留必须真划算**（§1.2）。否则这个选择是假的。
4. **六位仙人在第一幕要立住性格**（§5.1）。第二幕要杀他们，玩家得先认识他们。
5. **土地公和灶君要留住好感**（§5.2）。他们是第二幕的盟友，第一幕不要写成帮凶。
6. **第二幕的内容量不要失控。** 六位仙人、两条起点路线、三条力量来源 —— 这已经是一整个资料片。实现顺序建议：先把第一幕 60 层和第 60 层的两个选择做完整，第二幕从**一位仙人**开始验证手感，再铺开。
