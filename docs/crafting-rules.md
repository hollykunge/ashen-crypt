# 余烬地牢 · 规则锻造系统设计

建立在[阴阳五行世界模型](wuxing-world.md)之上。先读那份，这份只讲炉子怎么把材料变成装备。

## 0. 设计目标

不定义装备，只定义**世界如何把材料变成属性**。

- 策划维护的是**规则表**（形制矩阵、属性权重、生克参数、触发语法、格局阈值），不是装备清单。
- 玩家投入任意材料组合，系统按规则**推导**出装备，组合空间无限。
- 任何推导结果都落在**同一条功率预算曲线**内 ——"无限组合"不等于"无限变强"。
- 规则少到能印在一屏上。玩家靠理解规则做决策，而不是背装备名。

一句话：**装备不是物品表里的一行，而是一次规则求值的结果。**

## 1. 守恒律：功率预算

承重墙。

```
投料纯度总和   S = Σ(材料纯度 × 数量)
功率预算       P0 = min(S, 炉温上限) × 工艺系数
行向量         E[x] = Σ(材料纯度 × 数量 × 行向量[x])
阴阳           Y  = Σ(材料纯度 × 数量 × 阴阳) / S          # −1 纯阴 ~ +1 纯阳
行权重         w[x] = E[x] / ΣE                            # 归一化
```

**总量决定"有多强"，配比决定"强在哪"，阴阳决定"刚还是柔"。**

- `P0` 被炉温硬夹住 → 堆料无意义，溢出部分退化为残渣返还 60%。一次就教会玩家"投料不是越多越好"。
- 权重归一化 → 属性分配是一块**固定大小的饼**，想要某条属性高只能牺牲别的。自平衡。
- 权重低于 **8%** 的行视为**杂气**，剔除并返还残渣。保证装备描述永远干净。

### 1.1 炉温

| 炉温 | 预算上限 | 投料格 |
| --- | --- | --- |
| L1 | 18 | 6 |
| L2 | 30 | 8 |
| L3 | 48 | 10 |
| L4 | 72 | 12 |
| L5 | 100 | 12 |
| L6 | 135 | 12 |

投料格**封顶 12**，预算上限持续上涨 → 后期必须用高阶料才能填满。T4 单行纯料最稀缺，所以**走极致路线的成本体现在材料获取上**，不体现在规则里。

### 1.2 收益递减

所有百分比属性走软上限，点数 `p` 换算为实际值：

| 属性 | 公式 | 上限 |
| --- | --- | --- |
| 减伤 | `p / (p + 120)` | 75% |
| 暴击 | `p / (p + 100)` | 75% |
| 攻速 | `p / (p + 60)` | 60% |
| 移速 | `p / (p + 80)` | 60% |
| 破甲 / 穿甲 | `p / (p + 100)` | 60% |
| 格挡 | `p / (p + 110)` | 60% |
| 闪避 | `p / (p + 140)` | 50% |
| 冷却 | `p / (p + 150)` | 50% |

数值类（攻击、生命、灼烧、回血）线性，由预算本身封顶。

## 2. 生克结算：这套系统的新核心

上一版的混搭只是"切饼"。有了五行，混搭变成**有结构的交互**。门槛：参与生克的两行权重都 ≥ **15%**。

### 2.1 相生：不加功率，加有效纯度

```
对每个生对 (母 m → 子 c)：
    f = min(w[m], w[c])
    w[c] += f × 0.50          # 母气生子
    w[m] -= f × 0.15          # 子泄母气
然后重新归一化
```

**相生不增加总预算，但把预算集中到子行，从而抬高纯度倍率。** 结果是一条非常好用的规则：

> **相生让你用杂料做出接近纯料的数值。**

这很重要，因为掉落给你的本来就是杂料。6 甲木 + 6 丙焰（木生火）归一化后是 木 28% / 火 72% —— 纯度从 0.5 抬到 0.72，等于白捡一截数值，而且你还留着 28% 的木属性。

### 2.2 相克：耗散，或者化为反应

```
对每个克对 (克者 k → 受克 v)：
    g = min(w[k], w[v])
    w[v] -= g × 0.60                      # 受克方被削
    · 蛮干（默认）→ 耗散 += g × 0.25       # 直接扣预算
    · 调和（工艺）→ 反应份额 = g × 0.85    # 冲突转为签名效果
    · 制化（见 2.3）→ 无耗散
```

**不调和就是真亏**（验算：-30%）。这是全系统唯一的硬惩罚，而且它完全可预测 —— 玩家混了水和火，炉子会在预览里直接告警。

**调和不是补救，是另一条路。** 相克化成的不是普通词缀，而是五条**反应**签名效果，每件装备最多一处：

| 克对 | 反应 | 效果（强度 = `X`） |
| --- | --- | --- |
| 水克火 | **蒸汽** | 命中 20% 概率引发蒸汽爆发：`X × 2.5` 范围伤害并致盲 1 秒 |
| 火克金 | **腐蚀** | 攻击叠加腐蚀，每层降低目标减伤 `X × 0.15%`，最多 5 层，不可清除 |
| 金克木 | **撕裂** | 攻击造成流血，目标移动时每秒受到 `X × 0.35` 伤害 |
| 木克土 | **缠根** | 命中 15% 概率根须定身 1.2 秒，并吸取 `X × 0.5` 生命 |
| 土克水 | **泥沼** | 命中生成泥沼：减速 45% 并封锁目标回复，持续 `X × 0.06` 秒 |

只有五条，全部好记，而且是全游戏最有存在感的效果。它们来自世界模型里的**张力**，不是来自一张词缀表。

### 2.3 生克制化：五行俱全则自洽

**五行俱全（每行 ≥ 8%）且无一行独大（max ≤ 35%）** 时进入**生克制化**：

- 所有相克的耗散归零（生克自相调节）
- **纯度倍率取 `M = 1.00`** —— 均衡不以纯论
- 额外获得 **×1.35 制化加成**

这条不是为了平衡硬塞的，它就是五行理论本身说的事。而它恰好也是机制上必需的：没有它，五行俱全会同时触发全部 5 个克对，直接废掉。

### 2.4 生链：隔二则克的代价与回报

连续处于生链上的行数（每行 ≥ 15%）给加成：

| 生链长度 | 加成 |
| --- | --- |
| 1（单行或无链） | ×1.00 |
| 2（如木→火） | ×1.08 |
| 3（如木→火→土） | ×1.15 |
| 4 | ×1.25 |
| 5（即制化） | ×1.35 |

但[世界模型 §0](wuxing-world.md) 里那条结构性推论在这里变成实际代价：**任意三行连生必然夹带一处相克**。所以想吃 3 行以上的链加成，就必须同时掌握调和。这是一条天然的难度阶梯，不是人为设的门槛。

## 3. 阴阳：同一行的两种表现

### 3.1 分配与锐度

```
阳份 = (1 + Y) / 2        阴份 = (1 − Y) / 2
阴阳锐度 A = 0.95 + 0.30 × |Y|          # 极阴极阳 1.25，太极 0.95
```

极端阴阳**数值更高但只有一种形态**；太极**两种形态各半、数值略低，但另有格局与对怪优势**（见 [§3.2 伤害系数](wuxing-world.md)：太极永不吃"同性相滞"）。

### 3.2 完整求值公式

```
纯度       H = max(w)
纯度倍率   M = 1.00（制化时）  否则  0.70 + 0.60 × H
加成       B = 生链加成（制化取 1.35） × (1.22 若太极)
境遇       Q = Σ w[x] × q[旺相休囚死(x, 当令之行)]      # 见 §3.3，随层变化
势         S = 得势 1.10 / 失势 0.90 / 太极 1.00        # 装备阴阳 vs 当令阴阳
契合       F = Σ w[x] × f[十神组(x, 日干)] × 中和加成    # 见 §3.4，对一个角色固定
预算       P = P0 × (1 − 耗散)
可分配     alloc = P × (1 − 反应份额)

属性值 = round( alloc × w[x] × M × A × B × F × Q × S × 阴阳份 × k[stat] )
反应强度 =      P × 反应份额 × M × A × B × F × Q × S × 1.50
```

三组乘数，各管一件事：

| 乘数 | 含义 | 何时变 |
| --- | --- | --- |
| `M · A · B` | **内在品质** —— 这件东西铸得好不好 | 铸成即固定，存进存档 |
| `F` | **契合** —— 它合不合我的命 | 对一个角色恒定 |
| `Q · S` | **境遇** —— 它在这一层行不行 | 每层重算 |

玩家拿起一件装备时问的两个问题 ——"这件适合我吗""这件在这层好用吗"—— 正好对应 `F` 和 `Q·S`，互相独立。

### 3.3 境遇：装备强弱随层变化

完整定义在[世界模型 §3](wuxing-world.md#3-境遇旺相休囚死)，锻造侧只需记住：

> **当令者旺，令生者相，生令者休，克令者囚，令克者死。**
> `q` = 旺 1.30 / 相 1.12 / 休 0.98 / 囚 0.85 / 死 0.75，五值之和 **恰为 5.00**。

"当令"就是**本层的地气** —— 每层自带一个天干，它同时给出当令的行与阴阳。这两个乘数把装备从"固定数值"变成"随层变化的数值"，并且因为 `Σq = 5.00`，带来两条不需要配平的结构性结论：

- **五行均分的装备，`Q` 在所有层恒为 1.0000** —— 均衡路线一套打遍全层。
- **任一装备在一个均衡（五层）上的 `Q` 平均恒为 1.0000** —— 纯行与均衡**期望强度完全相等**，纯行方差 1.73 倍，均衡方差 1.03 倍。

所以玩家在"极致"和"均衡"之间选的不是强弱，是**风险**。

> `Σq = 5.00`（以及势的 `ΣS = 2.00`）是上面两条结论的唯一前提。调手感时可以改相对比例，**不要改总和** —— 给它加一条单元测试。
>
> **对玩家只说一个词"境遇"。** 行的旺相休囚死与阴阳的得势失势是它的两个分量，不要当成两套规则去教。

### 3.4 契合：装备合不合你的命

角色没有职业，只有命格。完整定义在[命格](bazi-destiny.md)，锻造侧只需记住：

> 装备的天干相对于你的**日干**构成**十神**之一。**身弱补我（印、比为用），身强泄我（官杀、财、食伤为用）。**
> `f` 分五组，两张端点表之和**各为 5.00**；再乘**中和加成** `1 + 0.14 × (1 − |身强度|)`。

所以**同一件掉落对不同命格的玩家价值差 2.5 ~ 3.3 倍**（已验算）—— 这是交易、赠予、回炉重铸的全部意义来源，而策划一行装备数据都没多写。

和前两条一样，`Σf = 5.00` 使得**五行均分的装备契合度恒为 1.00**：任何命格都能用，但也吃不到加成。

至此四条守恒律各管一个维度：

| 守恒律 | 约束 | 管什么 |
| --- | --- | --- |
| **预算守恒** | 配比归一化、炉温封顶 | **空间** —— 属性怎么分配 |
| **境遇守恒** | `Σq = 5.00`、`ΣS = 2.00` | **时间** —— 强度何时兑现 |
| **命格守恒** | `Σf = 5.00` | **人** —— 什么装备属于你 |
| **生克守恒** | `Σ生克 = 5.00` | **敌** —— 打谁有加成 |

四条都不制造强弱，只制造取舍。第四条见[成仙主线 §5](ascension.md#5-四条守恒律) —— 生克五值之和也恰好是 5.00，所以均衡装备打任何单一行的目标，生克收益恒为 1.00。

### 4.0 兵形：手感与数值分离

**角色没有职业**（[命格](bazi-destiny.md)），所以武器不受任何身份限制。兜率炉坊里另选**兵形** —— 剑、长枪、弓 —— 它只决定射程、攻击间隔与攻击形态：

| 兵形 | 射程 | 间隔 | 形态 |
| --- | --- | --- | --- |
| 剑 | 104 | 0.33 | 一轮两剑，合起来是一次普攻的伤害 |
| 长枪 | 152 | 0.45 | 平刺一条窄路，前后站成一串的都扎穿 |
| 弓 | 530 | 0.29 | 直线穿透两个目标 |

护甲、护手、鞋子在炉坊里另选**甲型** —— 布衣、皮甲、链甲（女角色的护甲叫丝衣、皮衣、盔甲）。甲型只换样子，不碰数值。

三件事彻底独立：**兵形决定手感，五行决定数值，命格决定适不适合你。** 一个癸水命主完全可以拿长枪 —— 他只需要用符合自己用神的材料去打这杆枪。

旧存档里已经去掉的兵形按打法归过来：长刃、双刀归剑，重锤归长枪，法杖、短杖归弓。

### 5.3 镶嵌与税

- 每件装备 0~2 个镶嵌槽。开第一个扣 **15%** 预算，第二个再扣 **25%**。强度 = 被扣掉的那份。
- 条件由装备**自身**的部位、主行、阴阳决定；动作由玩家**镶嵌的天干材料**决定。
- 两个槽的天干必须不同。

**60 条件 × 10 动作 = 600 种触发**，再加 30 种反应（5 克对 × 6 部位）。全部由规则推导，全部在预算内，全部可预测：

- 阴金武器 + 丁 → **暴击时点燃目标**
- 阳金护甲 + 甲 → **受击时回复生命**
- 阴水鞋子 + 辛 → **后撤后追加一次穿刺**

玩家读完两张表就能说出"我要一双后撤追击靴"，然后真的做出来。加一个天干动作 = 多 60 种触发。

## 6. 格局：取代套装

统计六件装备（按各自预算加权）的行画像 `R[x]` 和阴阳 `Y`。

### 6.1 行格局

| 格局 | 条件 | 效果 |
| --- | --- | --- |
| **专精格** | 某行 ≥ 55% | 该行属性 +15%；**处旺位时再 +10%，处死位时再 −10%**（放大赌性） |
| **相生格** | 生链 ≥ 3 行，各 ≥ 15% | 链上每环属性 +8%；受击时沿链转移 10% 伤害为灵力 |
| **均衡格** | 五行俱全，max ≤ 35% | 全属性 +10%；喂养惩罚**减半** |
| **相克格** | 一对克双方各 ≥ 30% | 反应强度 +40%；自身最大生命 −10% |

> 名字叫"专精格"（五行一气）而不是"专旺格"，是为了不和境遇里的**旺**撞词 —— 旺现在专指"当令"这一个技术含义。
>
> 均衡格原本写的是"免疫喂养"，现在降为"减半"：境遇倍率已经免费给了均衡路线 `Q ≡ 1.00` 的稳定性（[§3.3](#33-境遇装备强弱随层变化)），不必再叠一层。而专精格反过来**放大**境遇的赌性 —— 旺位更旺、死位更死，让极致路线真正成为高方差路线。

### 6.2 阴阳格

| 格局 | 条件 | 效果 |
| --- | --- | --- |
| **纯阳格** | `Y ≥ +0.6` | 阳形属性 +12%、暴伤 +15%；受阴系持续伤害 +15% |
| **纯阴格** | `Y ≤ −0.6` | 阴形属性 +12%、持续伤害 +20%；受阳系爆发伤害 +15% |
| **太极格** | `|Y| ≤ 0.15` | 全属性 +8%；**免疫同性相滞**（阴阳系数永不低于 1.00） |

**均衡格 + 太极格 = 一套打通关。** 阴阳轴与五行轴是正交的，两条轴各自的方差要分别对冲（已验算）：

| 构筑 | 五行方差 | 阴阳方差 |
| --- | --- | --- |
| 一气（纯一行） | 1.73x | 1.36x |
| 太极一行 | 1.73x | 1.00x |
| 五行均衡 | 1.03x | 1.36x |
| **均衡 + 太极** | **1.03x** | **1.00x** |

**只有两格同时成立才真的免换装**，代价是两条轴都放弃了上限。这是系统里唯一的免换装出口，刻意留着 ——"要上限还是要省事"由玩家显式选择，不是策划替他们决定。

行格局 16 种变体（专精 5 + 相生 5 + 均衡 1 + 相克 5）× 阴阳格 3 种 = **48 种格局**。无限套装，有限规则。

## 7. 工艺

工艺**不加功率，只重塑分配**。

| 工艺 | 效果 | 代价 |
| --- | --- | --- |
| 粗锻 | 预算 ×1.00，数值 ±20% 随机 | 便宜（随机由 `uid` 哈希决定，永不重掷） |
| 精锻 | 预算 ×0.90，结果完全确定 | 多耗 1 个同行高阶料 |
| **调和** | 化相克为反应（每件最多 1 处） | 反应占预算（§2.2） |
| 封印 | 指定一行降为杂气并返还 | 固定费用 |
| 转阳 | `Y += 0.25` | — |
| 转阴 | `Y −= 0.25` | — |
| 阴阳翻转 | `Y → −Y` | 首领核心 ×1 |
| **五行轮转** | 全部行沿生链前进一步 | 磨损 +1 |
| 熔合 | 两件成品合为一件 | 磨损 +1，见 §7.1 |
| 刻纹 | 触发条件的概率/强度 +50% | 首领核心 ×1，少 1 条属性 |

**五行轮转是一次确定性的重铸**：木→火→土→金→水→木，五次回到原点。这条规则直接消掉了生成式装备系统最大的挫败感 ——"刷到了好东西，但行不对"。

它和境遇合起来还有一条很漂亮的性质（[世界模型 §3.5](wuxing-world.md#35-性质四轮转阶梯律)）：沿生链轮转，境遇序列在**任何层**都是同一条阶梯 ——

```
死 → 囚 → 休 → 旺 → 相 →（回到死）
```

**处死位者，恰好三次轮转到旺位。** 玩家能确切算出要轮几次、每次停在哪个境遇。所以轮转必须保持确定性 —— 一旦改成随机洗属性，这条阶梯就没了，整套"玩家理解规则"的前提也跟着塌。

### 7.1 熔合：无限合成，收敛收益

```
P_new  = min(炉温上限, max(Pa, Pb) + 0.45 × min(Pa, Pb) × 0.8^磨损)
行向量 = 两者按预算加权平均（阴阳同理）
触发   = 玩家从双方槽中保留最多 2 个（照常收税）
磨损   = max(磨损a, 磨损b) + 1
```

磨损让系数 0.45 → 0.36 → 0.29 …… 几何收敛，叠加炉温硬顶。**"可以无限合成"是真的，"可以无限变强"是假的** —— 而且玩家能自己算出来这一点。

### 8.2 乘上境遇后的单层表现

同样七条路线，再乘各自的 `Q`（[§3.3](#33-境遇装备强弱随层变化)）。均衡均值与 8.1 的合计完全相同 —— 境遇不改变期望，只改变方差：

| 纯一行·极致 | 金 | 1.30 | 91.3 | 火 | 0.75 | 52.6 | 70.2 | **1.73x** |
| 四行连生·调和 | 火 | 1.12 | 82.1 | 水 | 0.86 | 62.9 | 73.5 | 1.30x |

| 二行相生 | 火 | 1.21 | 79.8 | 金 | 0.82 | 54.2 | 66.0 | 1.47x |
| 太极一行 | 金 | 1.30 | 84.6 | 火 | 0.75 | 48.8 | 65.1 | **1.73x** |

**均衡均值仍然全部收敛在 ±7% 内，但单层表现从 48.8 到 91.3 —— 几乎两倍。** 这就是换装的全部动力，而它一分钱平衡预算都没花：路线之间的期望是相等的，差的只是方差（1.03x ~ 1.73x）。

注意**太极一行**：它在阴阳轴上免疫克制，但五行方差仍是 1.73x（庚辛同属金）。两条轴要分别对冲，见 [§6.2](#62-阴阳格)。

### 8.3 七条路线的手感

- **纯一行** — 一条属性，数字碾压，没有任何花活；旺层无敌，死层废铁
- **二行相生** — 最省心的强，杂料也能做出纯料数值
- **三/四行连生** — 链加成最高，但必须会调和
- **二行相克·调和** — 属性只有一半，换一个全场最炸的反应
- **五行均衡** — 十条小属性，哪层都是 `Q = 1.00`，一套打到底
- **太极** — 刚柔各半，永不吃阴阳克制（但五行上仍需换装）

## 9. 推导示例

### 9.1 二行相生：甲 6 + 丙 6，武器，精锻

```
S = 6×3 + 6×5 = 48      P0 = min(48,48) × 0.90 = 43.20
行  木 18 / 火 30  →  w 木 0.375 / 火 0.625
相生 木生火 f = min(0.375, 0.625) = 0.375
     w火 += 0.1875 → 0.8125   w木 −= 0.0563 → 0.3188   归一化 → 木 0.282 / 火 0.718
相克 无（木克土、火克金，均不在场）   耗散 0%
H = 0.718 → M = 1.131     Y = +1.00 → A = 1.25     链 2 → B = 1.08
```

| 行 | 权重 | 阳形 | 计算 | 结果 |
| --- | --- | --- | --- | --- |
| 火 | 0.718 | 攻速 `k=0.45` | 43.2 × 0.718 × 1.131 × 1.25 × 1.08 × 0.45 | 攻速点 21.3 → **+26%** |
| 木 | 0.282 | 吸血 `k=0.15` | 43.2 × 0.282 × 1.131 × 1.25 × 1.08 × 0.15 | **吸血 +2.8%** |

→ `甲丙·相生疾刃`：攻速 +26% · 吸血 +2.8%

### 9.2 二行相克·调和：癸 6 + 丙 6，武器，精锻 + 调和

```
S = 60 → 溢出 12 纯度退残渣      P0 = min(60,48) × 0.90 = 43.20
行  水 30 / 火 30  →  w 各 0.50        Y = (−30 + 30)/60 = 0.00  → 太极！
相克 水克火 g = 0.50 → w火 −= 0.30 → 0.20    归一化 → 水 0.714 / 火 0.286
     调和：反应份额 = 0.50 × 0.85 = 0.425     耗散 0%
H = 0.714 → M = 1.129    A = 0.95    太极 → B = 1.22
alloc = 43.2 × (1 − 0.425) = 24.84      阳份 = 阴份 = 0.50
```

| 行 | 形 | 属性 | 值 |
| --- | --- | --- | --- |
| 水 | 阳 / 阴 | 冲击 / 冰冻减速 | **7** / **6** |
| 火 | 阳 / 阴 | 攻速 / 灼烧 | **2** / **4** |

```
反应强度 X = 43.2 × 0.425 × 1.129 × 0.95 × 1.22 × 1.50 = 36.0
→ 蒸汽反应：命中 20% 概率爆发 36.0 × 2.5 = 90 点范围伤害并致盲 1 秒
```

→ `太极·水火反应剑·蒸汽`：冲击 7 · 冰冻减速 6 · 灼烧 4 · 攻速 2 · **蒸汽爆发 90（20%）**

**同样十二格料**：9.1 是 +26% 攻速的稳定输出刀，9.2 是四条小属性外挂一个 90 点 AOE 爆发。这个取舍就是整套系统要让玩家反复做的决定。

### 9.3 纯一行：纯钢 4，武器，精锻

```
S = 56 → P0 = min(56,48) × 0.90 = 43.20    w 金 1.00    H = 1.00 → M = 1.30
Y = +1.00 → A = 1.25     链 1 → B = 1.00
```

→ `纯阳金长枪`：攻击 +70（内在品质）。一条属性，没有别的。

**但这 70 点只是均衡平均值，实际每层都不一样：**

| 层属 | 金的境遇 | `Q` | 实际攻击 | 打本层怪（生克） | 净战力 |
| --- | --- | --- | --- | --- | --- |
| 金层 | 旺 | 1.30 | **91** | 同气 ×0.88 | 1.14 |

## 10. 命名与呈现

### 10.1 生成式命名

```
[格局前缀][阴阳 + 行组合][工艺][形制]·[触发或反应]
```

- 纯度 ≥ 0.8 → `纯` + 阴阳 + 行（`纯阳金长枪`）
- 二行以上 → 按权重排的行组合（`木火相生剑`）
- 太极 / 均衡 / 相克 → 格局前缀（`太极·水火反应剑·蒸汽`）

**名字里不写天干。** 天干只是材料与地气的内部索引，玩家读装备不该先认字 —— 阴阳写成「阳」「阴」，行写成「金木水火土」。中文五行词汇本身足够丰富，生成名几乎不会出现机械感。玩家可改名，改名后进图鉴。

### 10.2 兜率炉坊 UI（规则能不能被理解，全看这里）

- **投料盘 + 部位 + 工艺**，右侧**实时预览**属性、触发、反应、格局变化。**确认前不扣料** —— 预览就是整个教学系统，玩家靠试错学规则，不靠消耗材料学规则。
- **五行罗盘**：五边形雷达叠加生克箭头。相生画成绿色箭头，相克画成红色箭头并**直接标出耗散百分比**和"调和可化为蒸汽反应"的提示。玩家看一眼就知道自己干了什么。
- **阴阳滑条**：显示 `Y` 与阳形/阴形的分配比例。
- **推导面板**：逐行展示"为什么是这些属性"（`43.2 × 火 71.8% × 纯度 1.131 × 阴阳 1.25 × 生链 1.08 × 攻速 0.45 = 21.3`）。这是把规则交给玩家最直接的方式。
- 属性条目**最多显示 4 条**，其余合并为残渣提示（均衡路线有 10 条，必须折叠）。
- **格局面板**：六件装备的行画像雷达 + 当前格局 + "再把一件换成木即可成均衡格"这类提示。
- **境遇角标**：每件装备常驻显示它在**当前层**的境遇（旺/相/休/囚/死）与 `Q` 值。进层前给一张全套装备的境遇总览，并在主力装备处死位时直接告警。**看不见的倍率等于不存在的倍率** —— 玩家只会觉得手感飘。
- **契合角标**：每件装备同时显示十神与 `F` 值，用神绿、忌神红。背包要能按契合度排序、一键筛出忌神装备，并直接给出"轮转 N 次可转为用神"的提示。玩家不该需要自己算十神。
- **轮转预览**：装备详情里直接画出"再轮 N 次 → 什么行 → 什么境遇"的阶梯，让玩家一眼看出离旺位还差几步。

### 10.3 玩家规则卡（游戏内一屏，九行）

1. 材料只有五行两性，合起来十个天干：**金锐 木生 水寒 火燃 土载**，**阳刚阴柔**
2. 投料总量决定**有多强**，配比决定**强在哪**，阴阳决定**刚还是柔**；总量有炉温上限，多投浪费
3. 同样的料放在不同部位，变成不同属性
4. **相生**（木火土金水循环）会把力量聚到子行 —— 杂料也能做出纯料的数值
5. **相克**（隔一个打一个）会白白耗散，除非用**调和**把它化成反应绝技
6. **五行俱全且均衡**则生克自洽，走均衡路线
7. 装备在每层有**境遇**：**当令者旺，令生者相，生令者休，克令者囚，令克者死** —— 越偏的装备，旺时越强、死时越废，但十层一轮下来谁也不占便宜
8. 装备还要**合你的命**：看它的天干对你**日干**是什么十神 —— **身弱补我，身强泄我**
9. 六件装备的五行画像决定**格局**；**五行轮转**能把装备沿生链推一步（死→囚→休→旺→相），**熔合**能两件并一件但有磨损
10. 打怪也是这套：**克它翻倍，被它克打不动，生它反而给它回血**

## 11. 接入现有工程

[gear.gd](../mobile/scripts/gear.gd) 的 `bonuses()` 已经是"返回一个扁平属性字典给 [combat.gd](../mobile/scripts/combat.gd) 消费"的结构。规则引擎产出同一个字典即可，战斗侧改动集中在新状态效果与生克乘法。

### 11.1 要删的

- `equipment.gd::ITEMS`（16 件固定装备）、`AFFIXES`（6 条词缀）、`SETS`（3 个套装）

### 11.3 装备实例：存输入，不存结果

规则改了，旧装备自动跟着改，不需要写迁移：

```gdscript
{
  "uid": "a7f3",                       # 稳定 ID，也是粗锻随机的种子
  "slot": "weapon",
  "process": ["forge_fine", "harmonize"],
  "materials": {"gui": 6, "bing": 6},  # 天干 → 数量
  "sockets": [],                       # 镶嵌的天干
  "rotation": 0,                       # 五行轮转次数
  "wear": 0,
  "name": ""                           # 空 = 用生成名
}
```

核心是一个纯函数，**当令作为参数传入**（境遇每层重算，不进存档）：

```gdscript
static func derive(item: Dictionary, forge_level: int, ling: String = "") -> Dictionary
# → {"stats": {...}, "triggers": [...], "clash": {...}, "wuxing": {...}, "yin_yang": 0.0,
#    "purity": 0.714, "budget": 43.2, "jingyu": {"jin": "旺", ...}, "q": 1.30,
#    "name": "...", "steps": [...]}        # steps 给推导面板
```

`ling` 留空时 `Q = 1.0`，返回**内在品质** —— 炉坊预览、图鉴、装备对比都用这个口径，否则玩家换层回来会以为装备被偷偷改了。传入当令才得到该层实战值。

`bonuses()` 变成：遍历 6 件 → `derive(item, level, 当前层属)` → 累加 → 算 `R[x]` 与 `Y` → 叠加格局 → 过软上限曲线。存档升到 **v4**（v3 旧存档按材料总价值折算为等值天干材料返还）。

必须有的单元测试：

```gdscript
# 境遇守恒：这两条是 §3.3 全部结论的前提
assert(sum(JINGYU.values()) == 5.00)
for ling in WUXING:
    assert(is_equal_approx(_q_of_uniform_item(ling), 1.0))      # 均衡恒定
for x in WUXING:
    assert(is_equal_approx(_mean_q_over_cycle(x), 1.0))         # 均衡均值恒定
```

## 12. 已知风险与对策

**最大的风险仍然是收敛：玩家算出唯一最优配比，"无限组合"退化成"一种组合"。** 五行版比上一版强在这里 —— 对策长在世界模型里，不是外挂的补丁：

1. **境遇倍率**（§3.3）—— 装备强度**本来就随层变化**，所谓"最优配比"只在五分之一的层里成立。而且它不靠惩罚实现 —— 期望处处相等，只有方差不同。
2. **命格契合**（§3.4）—— 连"最优配比"这个说法都不成立了：**每个玩家的最优配比都不一样**，由日干与身强弱决定。这是最彻底的一条，因为它让收敛**在玩家之间**都无法发生。
3. **喂养机制**（[世界模型 §4.3](wuxing-world.md#43-喂养整套设计里最重要的一条)）—— 万能配比必然在某些层主动奶怪。玩家能理解，不会觉得被针对。
4. **地气**（[世界模型 §5](wuxing-world.md#5-山门地气与十层一轮)）—— 世界本身每层换两个正解（稳解与锐解），十层走满一遍天干。
5. **七条路线的十层均值已验算收敛在 ±7%**（§8.2），**五档命格收敛在 1.4% 内**（[命格 §3.1](bazi-destiny.md#31-中和加成守恒律挡不住挑最好的那件)）—— 没有一条显然最优，也没有一条是死的。
6. **均衡格 + 太极格**给"不想换装"的玩家一条明确的低上限出口（§6.2），而且它在命格维度上也成立（`F ≡ 1.00`），四条守恒律同时兜底。
7. **软上限**（§1.2）让单属性堆到后期性价比崩掉。

必须留的手段：

- **`STAT_WEIGHTS`、`SHENG_KE_PARAMS`、`CLASH`、`JINGYU`、格局阈值全部要能热更。** 生成式系统的平衡只能靠上线后看数据调，必须留出调的手段。
- **但 `JINGYU` 的五值之和锁死在 5.00。** 调方差就改相对比例（例如旺 1.22 / 死 0.83 是更温和的一档），改总和会直接打破"期望相等、只有方差不同"的结构，所有路线平衡随之失效。用单元测试盯住（§11.3）。
- **埋点记录每次锻造的配比与路线**，用分布图看是否收敛到单一配比。这是这套系统唯一的健康指标。

**认知负荷是这一版最该担心的事，超过平衡本身。** 加上命格之后，玩家要同时理解**五套**规则：预算守恒、生克、阴阳、境遇、命格 —— 再加本层地气的遭遇效果。**这已经是手游能承受的上限，不要再加第六层。**

完整的分段解锁计划与两条具体削减建议（势并入境遇、大运与流年整条删掉）见[命格 §7.1](bazi-destiny.md#71-规则数量已经到顶不要再加第六层)。要点：

1. **第 1–3 层**只讲投料 → 属性；境遇只用颜色角标暗示，不出数字
2. **第 1 个首领后**解锁生克与分层应对
3. **第 11 层（第二个境界）**解锁境遇数值与轮转预览
4. **第二个境界中段**解锁命格面板
5. 调和/反应、熔合、格局放到第三个境界

**创建角色时不要解释命格的数学** —— 只说"选你的时辰"，并展示那 12 条看得懂的天赋。规则多不是问题，一次性全摊开才是。

其他：

- **可读性是第一优先级。** 600 种触发 + 54,600 种基础装备，预览面板和推导面板做不好，玩家会直接放弃理解规则，整套设计就白做了。**预览面板的优先级等于规则引擎本身。**
- **耗散必须预警。** 玩家混了相克却不调和会亏 30%。预览里必须红字告警并给出"调和可化为蒸汽反应"的一键建议。亏了而不知道为什么，会被当成 bug。
- **数值兜底。** `derive()` 要有断言：任何属性不得超过该炉温理论上限的 1.5 倍。
- **粗锻随机必须可复现。** 用 `uid` 做种子，否则读档重掷会被玩家当成 bug 或拿去刷。
- **五行轮转不能变成洗属性赌场。** 它是确定性的（固定前进一步），这是刻意的 —— 一旦改成随机重铸，整套"玩家理解规则"的设计前提就塌了。
