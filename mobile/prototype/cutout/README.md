# 皮影小样

AI 出拆件图，脚本切件，Godot 里挂骨骼、用代码算动作，换装只换部件图。两个测试角色：

- `shanxiao/`：山魈。6 件（头、躯干、上臂、前臂、大腿、小腿），光身加两套青铜护甲。
- `hero/`：男主角。9 件，比山魈多出长衣下摆前后片和一把剑；布衣加皮甲、链甲。

| 文件 | 干什么 |
| --- | --- |
| `gen.sh <角色> <种类>` | 调 codex 按 `<角色>/prompts.json` 出图，每种 3 张备选到 `<角色>/source/` |
| `cut.py` | 白底转透明、按连通块切件；`--like parts` 把护甲件对齐到光身件并打印重合度 |
| `<角色>/rig.json` | 每个部件的关节点和缩放（部件图里的像素坐标），可覆盖待机、走路幅度和攻击关键帧 |
| `<角色>/demo.json` | 演示里并排哪几套外观 |
| `cutout_rig.gd` | 骨骼、换装、下摆、握剑；待机／走／跑／攻击。腿用 IK（先定脚踩哪再倒推关节，支撑脚不打滑），跑步有腾空和踢脚跟；前臂、头、下摆、剑用弹簧跟随，换动作时平滑过渡 |
| `demo.tscn` / `demo.gd` | 演示场景 |
| `render.sh <角色> <目录>` | 渲成 mp4 和 gif |
| `tune.sh [角色]` / `tuner.gd` | 调参面板 |
| `compare.py hero <输出.png>` | 笔直站姿跟设定图侧面并排，画身高 1/16 的方格（横比高低、竖比粗细），并打印几处宽度的比值，用来校 `rig.json` 里各件的 scale |

## 换装（按装备槽）

主角的部件按槽分组（rig.json 的 slots）：护甲（躯干、两只上臂）、裤子（臀胯、大腿、靴口上的裤管）、护手（两只前臂、握剑手）、鞋子（靴子）。
每个槽可以单独换，混搭也对得上。新出一整套装备：

    cd hero
    python3 ../master.py compose                     # 把所有能换的光身部件按真实比例拼成 source/master.png
    ../gen.sh hero set-leather                       # 在总图上让 AI 一次改出整套（提示词在 prompts.json）
    python3 ../master.py extract source/set-leather-1.png set-leather   # 按位置切回、对齐、打印重合度

现在有布衣（parts）、皮甲（set-leather）、铁甲（set-iron）三套。小腿在靴口处切成两件：shin 是裤管（裤子槽），boot 是靴子（鞋子槽）。

## 调参面板

    prototype/cutout/tune.sh            # 调主角（在 igame 目录下运行）
    prototype/cutout/tune.sh shanxiao   # 调山魈

左边实时看角色动，右边拖滑块；上面的下拉框切换动作（跑步、走路、待机、劈砍、站直对比），下面一排按槽选护甲、裤子、护手、鞋子，可以混搭，
「播放速度」可以放慢看。鼠标停在参数名字上有说明。满意了点「保存」写回 `<角色>/rig.json`
（第一次保存前会把原文件备份成 `rig.json.bak`），「撤销改动」回到上次保存的样子。
「站直对比」把设定图侧面缩放到一样高放在旁边，画 1/16 身高的方格，调外观里的部件大小时用。
「劈砍关键帧」一组里选要调的帧（起手、挥下、打中、收势），勾「定格在这一帧」就停在那一帧看，拖滑块调各关节、重心、前脚迈出和这一帧的时间；上面会显示这一帧剑尖朝哪。「打中」后面的停顿帧跟「打中」同一个姿势，一起改。剑的朝向 = -(上臂 + 肘) + 手腕 + 手里剑柄斜度（0 朝正前、正数剑尖往下、-90 朝上），照这个算关键帧；劈砍时手腕可以压到 attack_wrist 度。挥剑那一段会画刀光（weapon 的 tip 标剑尖）。

重出一遍（在角色目录里运行）：

    cd hero
    ../gen.sh hero parts                    # 出 3 张光身拆件图，挑一张拷成 source/parts.png
    python3 ../cut.py source/parts.png parts --names head,torso,upper_arm,forearm,thigh,shin,skirt_front,skirt_back,weapon
    ../gen.sh hero armor-leather            # 在 source/parts.png 上加护甲
    python3 ../cut.py source/armor-leather-1.png leather --like parts
    # 再删掉没加护甲的件（头、剑等），让它们沿用光身版

主角的经验（第一轮的坑）：

- 提示词要写清比例（几头身、裆在身高一半、腿比躯干长多少）、躯干要「直背、前后薄」，否则 AI 画成矮胖驼背。
- 握剑的手要画成「从拇指一侧看、剑柄前后穿过拳心」，手背朝镜头的拳头握不住侧面的剑。
- 护甲提示词按位置指部件（「右上角那件袖子」），按编号指会被 AI 数错，把护肩画到前臂上。
- 比例最后靠 `compare.py` 对着设定图调 scale，不用重出图。scale 可以写成 `[横, 竖]`：靴子太粗就只收窄，腿不会变短。
- 脖子：头的接点要在衣领开口正中，头垫在躯干下面（rig.json 里 head 的 behind），让衣领盖住脖子根的切口。
- 僵：腿按角度摆一定打滑，要用 IK 让脚踩住地；拿剑的手走路时要垂在身侧摆，平举在身前就是僵尸。
- 臀胯（pelvis）：腰带下面一块裤子上段，后面鼓出臀部、前面是胯，压在两条大腿上面，髋关节标在它里面（pelvis 的 hip）。没有它，腿就像直接插在腰上。AI 画的臀部偏尖，原图存成 pelvis.orig.png，pelvis.png 是把后面的轮廓按一段圆弧修过的。
- 关节圆头：`joint_caps.py` 把大腿顶端修成以髋关节为圆心的半圆，转多少度轮廓都不变；不修的话大腿抬起时顶端会从臀部后面翘出去、往后蹬时在胯前顶出尖角。
- 腿「回弹」：一是摆腿路线不能往前多探再缩回来，二是 IK 在腿快伸直时膝盖会一帧之内绷直又弯回去，用软 IK（SOFT_IK）收住；三是脚的落点要在腿够得着的范围里（后蹬距离² + 胯高² < 1），够不着腿就会提前绷直、脚被拽离地面。
- 站直腿弯：软 IK 只能给走、跑用（_soft 按动作切换），站着用了腿永远伸不直。
- 脚踝：靴子在脚踝（shin 的 ankle、boot 的 split）切开，脚绕脚踝转，踩地时放平；IK 对准脚踝，脚放平后鞋底正好贴地；boot 的 foot_scale 单独缩脚。
- 驼背：AI 画的躯干后背是一道圆弧，`back_trim.py` 沿直线把鼓出去的削掉（原图 torso.orig.png）；躯干 tilt、头 tilt 是站姿底子的角度。
  站得正不正用 `plumb.gd`（铅垂线）量：脖子根应在髋关节正上方略靠前（0～3°），耳朵在脖子根正上方（-2～2°）。
  主角现在是躯干 tilt +4、头 tilt 0，头的转轴（head 的 pivot）上移到 (108, 170)，让头往衣领里沉一截：
  AI 画的脖子本身往前斜约 17°，挪位置、转角度都救不回来（往上露出斜脖子像探头，往下沉像缩脖子）。
  最后是让 AI 只重画脖子（gen.sh hero head_neck，source/head-edit.png 是放大后的原头），脸和头发不变、脖子竖直粗壮，
  脖子再往下用拉伸延长一截（head.upright.png 是没延长的）。头的转轴 (109, 180)：转轴在图里越靠上，脖子藏进衣服越多、露得越短；
  躯干上的脖子接点 (84, 28) 在领口正中。脖子底用 joint_caps 的办法修成以转轴为圆心的半圆（head.extended.png 是修之前的），
  劈砍时上身前压、头往回转，脖子底也不会从领口前面甩出来；头只抵消一半上身前倾。劈砍定格特写：attack_closeup.gd。衣领用躯干图原来的（试过加一圈立领，停用成 _collar）。原图存成 head.orig.png。
  特写看脖子：`godot --path mobile --resolution 900x900 --script res://prototype/cutout/closeup.gd -- stand 输出.png [放大倍数，默认 9.6，4.8 看到腰]`。看头正不正要跟设定图并排比，别只看数字。别凭感觉往后立：后背鼓包削掉以后再往后立，人就往后倒、仰着头。远侧手脚往后错开（FAR_SHIFT）别太多，否则肩头从后背露出来像驼峰。
- 劈砍时腿抖：上步跨两段关键帧时，每段各抬一次脚，交界那帧脚点地再抬，膝盖一弯一直。现在连着的几段合成一次抬脚（sin² 曲线，起落都平）；
  IK 算出的腿部角度再过一层很硬的弹簧（leg_* 的 SPRINGS），压住腿快伸直时的跳变。`attack_jitter.gd` 量膝盖每帧变化和来回反向次数。
  弹簧追角度要按最短方向（IK 的小腿角会跨 ±180°，不处理就转一整圈）。改完动作跑一遍 `spin_check.gd`：整段演示里一帧转超过 60° 的骨骼都会列出来。
- 停用某件部件：rig.json 里把它的键名前加下划线（比如 `_skirt_front`），骨骼就当没有这件；去掉下划线就恢复。主角现在停用了前后摆。
- 下摆穿模：前后两片都要压在两条腿前面（侧面看到的是包住双腿那圈布的外侧），腿只从下摆底下和开衩露出来；每片切上下两截（rig.json 的 split），上截被大腿顶起来，下截往下垂、跑起来往后飘。
- 握剑：拳头跟前臂画在一起时，剑一转剑柄就从拳头里斜着露出来；把拳头切下来单独转，护腕又会叠两层、手像贴上去的。
  最后的做法是单独出一张「握着剑柄的手」（`gen.sh hero hand`，手背朝外、指节顺着剑柄、剑柄斜指前下）：
  近侧前臂只用到护腕下沿（forearm 的 split，overlap 0），手的转轴标在手腕横纹，往上只留一小截塞进护腕；
  手里画的剑柄两头削掉，剑本身压在拳头底下、顺着手里剑柄的方向（hand 的 grip_angle）挂；手腕只许转 ±15°。
  出这张图时提示词里写「sword」偶尔会被出图工具的暴力过滤拦下，多出几张就行。
- 远侧手臂：隔着身体看到的是左臂的内侧。单独出图比例对不上，要用改图的方式（`gen.sh hero far_arm`，在光身拆件图上只把上臂、前臂改画成内侧左臂，拳头改成掌心一侧），
  轮廓跟近侧一样，rig.json 里写 `"same_as": "upper_arm"` 共用近侧的关节点和缩放，近侧怎么调远侧跟着变。
- 两腿之间垫一块裤裆（crotch），不然迈大步时两条腿像飘着。
- 手腕：`wrist_cut.py` 按颜色把前臂图里原来的拳头抠掉、保留护腕本来的底边；手的手腕顶收成圆弧塞进护腕。
- 调参面板保存时只并入面板管的参数，面板外加的部件不会被冲掉；但面板打开后改过 rig.json 的话，最好重开面板再调。
- 录帧前要强制画一帧（demo.gd 里的 force_draw）：屏幕关了、锁屏或窗口被挡住时 macOS 不画窗口，截到的全是旧画面。
- 宽度表量的是整个轮廓：设定图站姿露出了后面那条腿，膝盖、小腿两行的比值会偏小，要对着方格看前面那条腿。

开窗口看：`godot --path mobile res://prototype/cutout/demo.tscn -- hero`
