# 女主光身底图（body_f）

粉白皮影底身，以后衣服、护甲按槽叠在上面。美术原稿在 `source/`：分片 PSD 原稿和 GIMP 工程（.xcf）、修过瑕疵的 `-修瑕.psd`、装备模板 `女主装备模板.psd`。
原稿 16 层，图层顺序固定。`source/` 有 `.gdignore`，Godot 不扫描。

```sh
cd mobile/prototype/cutout/body_f
python fix_psd.py      # 修原稿的瑕疵（手腕接缝、拳头皮子和铆钉、杂点），另存 …-修瑕.psd，不动原文件
python export_psd.py   # 从修瑕版导出 parts/，按铆钉定关节点，同步进 rig.json 的 parts
```

- **左右一律是角色本人的左右**，和 PSD 图层名一致；文件名也照图层名：`upper_arm_right.png` 就是「右上臂」那层。
  右边身体的件排在画布左边，左边身体的件排在画布右边。说画布上的位置时写明「画布左边 / 画布右边」。
- 人物侧身朝右，观众看到的是她身体的右侧，所以骨骼里的**近侧 = 右**（画在身体前面，右手握刀拳），**远侧 = 左**（画在身体后面，压暗）。
  `rig.json` 里每个骨骼部件用哪张图写在 `file`：近侧上臂、前臂、手 = 右上臂、右前臂、右手握刀拳；远侧 = 左上臂、左前臂、左手；
  近侧腿 = 右大腿、右小腿、右脚，远侧腿 = 左大腿、左小腿、左脚（左右大腿轮廓是镜像的，不能共用）；
  张开的右手（`hand_right.png`）暂时没用上。
- 手按排布里挨着的那条前臂原来的斜度转正（右手握刀拳在排布里叠在左手的位置上，按左前臂转）。
- 躯干连着内裤是一整块：近侧胳膊、腿挂在后肩、后胯，远侧挂在前肩、前胯（`far_shoulder` / `far_hip`），腿的挂点跟着躯干转。
- 脚是单独一件，挂在小腿下端的铆钉上，压在小腿下面。
- 刀借刀客的（`parts.weapon.src`）。
- `export_psd.py` 只改 `rig.json` 里的关节点和 `file`；缩放、握刀位置（`hand.grip` / `grip_angle`）和动作参数是手调的，重新导出不会被覆盖。

## 装备

装备不分布衣、皮甲、链甲，款式随意。画装备用模板 `source/女主装备模板.psd`（`python make_gear_template.py` 生成）：

- 「底身（参考，勿动）」组是修瑕版底身，只当底稿，不要改。
- 每个槽一个组，组名写成「槽-款式名」，款式名随便起（比如「护腿-青布绑腿」）。画新款式就把整组复制一份、改款式名。
- 组里每个部件一层，图层名照底身的部件名（角色本人的左右）。GIMP 给重名的层自动加的「 #1」不用管。

| 槽 | 部件图层 |
|---|---|
| 上衣 | 躯干、右上臂、左上臂 |
| 护腕 | 右前臂、左前臂、右手握刀拳、左手 |
| 护腿 | 右大腿、左大腿、右小腿、左小腿 |
| 靴子 | 右脚、左脚、右靴筒、左靴筒 |

- 某层留空 = 这款装备不盖这个部件，那里露出底身。
- 照着底身那件的位置画，可以画出轮廓外（盔甲比身体宽、衣摆往下垂都行）；**关节圆头和铆钉的位置不要挪**，骨骼按铆钉转。
- 躯干连着内裤是一整块，所以上衣盖的是整块躯干，腰下的衣摆、臀部要一起画。
- 靴筒是新加的一节：挂在小腿上、压在小腿外面，画靴子包住小腿下段的那部分；脚本身压在小腿下面。

游戏里怎么换图：每件上衣、护腕、护腿、靴子记一个款式名（`item.style`，在炉坊里选），皮影主角按款式名换这一槽的部件
（`scripts/gear_styles.gd`）。款式图放在 `gear/<槽>/<款式名>/`，文件名同 `parts/`（比如 `gear/greaves/青布绑腿/thigh_right.png`），
`gear/styles.json` 列出每个槽画了哪些款式：`{"greaves": ["青布绑腿"]}`。没画的部件、没画的款式都用光身原图。
槽名：armor 上衣、gloves 护腕、greaves 护腿、boots 靴子；每个槽换哪些骨骼部件写在 `rig.json` 的 `slots`。
把模板里画好的装备拆成这些文件的脚本还没写，等第一款画好再写。
