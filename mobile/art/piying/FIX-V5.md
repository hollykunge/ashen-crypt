# 真机试玩后的返工（交给 Codex）

用户把 APK 装到手机（1080×2354，约 19.6:9，Android）上试玩后的意见，原话：

> 人物身上的签子怎么还有；开机页面人物和页面元素都被分辨率搞变形了，需要自适应；
> 人物拼接也不是按照锚钉对齐的；人物的动作也不协调，很奇怪。

真机截图在 `mobile/art/piying/phone-issues/`（title-phone.png、armory-phone.png、hero-joints.png 是行装页主角放大）。
**这个目录是给你看的问题记录，改完后删掉它。**

## 1. 签子一根都不能有

- 标题页主角（`art/piying/v4/title.webp`、`title-tall.webp`，原图 `art/ui-icons/raw/night-title.png`）身上画着签子：手腕连到地上的细杆，背后手里的长杆。
  重出标题图：主角**手里直接提着灯笼**（或提一根很短的灯笼提杆，只在手里，不连到身体、不伸到地面），身上不连任何杆子。其余构图照旧（月、柳、桥、倒影、芦苇）。
- 全项目再查一遍：代码画的签子（draw_line 之类）、图集里烘进去的签子、精怪图里的杆，全部去掉。截图核对每个页面、每种怪。

## 2. 自适应，任何分辨率都不能变形

- 现在有些图不是生成时的原始比例，被**非等比缩放**过（例如 title-tall.webp 852×1846、raw/night-title.png 同尺寸，比例 0.46，和出图工具的原生比例不一样，人物被拉高了）。
  **所有图都必须等比**：背景用「铺满裁切」（cover），按画面重心对齐（人物、标题那一块不能被裁掉）；需要更高或更宽的画面时，
  用分层拼（天空/幕布底色往上延展、远景居中、前景芦苇贴底贴边），或重出一张原生比例合适的图后再裁切，**不准直接拉伸**。
  把所有页面用到的大图都检查一遍：title*.webp、river*.webp、river-portrait.webp、armory-stage.webp、banners*.webp、stage.webp、stage-portrait.webp 等，
  有拉伸过的就重做。
- 界面元素：九宫格按钮、面板只拉中间、边角不变形；圆形徽章、头像框、灯盏、图标必须保持正圆、等比；字不能被压扁拉长。
  检查所有 TextureRect 的 stretch_mode / expand_mode、StyleBoxTexture 的边距、按钮和图标的 custom_minimum_size，凡是会非等比缩放的都改掉。
- 布局要随屏幕比例自适应（project.godot 是 canvas_items + expand，基准 390×844）：内容区居中、关键元素靠安全区（刘海、底部手势条，用 DisplayServer 的 safe area），
  长屏多出来的空间给背景，不要把元素拉大变形。
- **验收分辨率**（每个都截标题、挂机、连战、行装、锻造、设置）：1080×2354（用户手机）、1080×1920（16:9）、1440×3200（20:9）、1536×2048（平板 3:4）、
  2354×1080 和 1920×1080（横屏）。桌面上用 `godot --path mobile --resolution WxH`（可等比缩小，如 540×1177）跑截图脚本。
  截图存 `mobile/art/piying/ui-shots-v5/<分辨率>/`，自己逐张看有没有拉伸、裁掉关键内容、元素出界。

## 3. 人物按锚钉拼接

男主角 `prototype/cutout/piying/`、女主角 `prototype/cutout/nvjiang/`：部件图上画着铜铆钉圆盘（关节），现在骨骼的转轴和这些画好的铆钉不重合，
代码又在别处另画了一套铆钉（`scripts/puppet_hero.gd` 的 draw_circle），结果一个关节出现两颗钉、钉子飘在袖子中间、上臂和前臂错位（见 hero-joints.png）。

- 写一个脚本，**自动在每个部件图里找出画好的铆钉圆心**（铜色圆盘，可以用颜色阈值 + 圆检测），输出每件的铆钉坐标；
  把 `rig.json` 里每个部件的转轴（pivot）设在它自己的铆钉圆心上，父部件上对应的挂点（例如躯干的肩、上臂的肘、大腿的膝）也设在父部件对应铆钉的圆心上，
  让子部件的铆钉正好压在父部件的铆钉上，旋转时围着这颗钉转。没画铆钉的接口（比如头和颈、握刀的拳）按轮廓接缝定，并补画或不画钉，保持一致。
- **删掉代码另画的铆钉**，只用部件图上画的那一颗。一个关节只能有一颗钉。
- 出一张调试图：每个部件叠加红十字标出转轴、绿圈标出检测到的铆钉，站直姿势下整个人拼起来，存 `ui-shots-v5/rig-debug-<角色>.png`，确认十字都落在钉心上。
- 部件之间不能有缝、不能错位：肩、肘、腕、髋、膝、踝在所有动作的所有帧里都要连着。

## 4. 动作要协调自然

现在用的是「皮影一颠一颠」的走法（cutout_rig.gd 的 _pose_puppet_gait / _pose_puppet_idle，rig.json 的 style = "piying"），用户觉得奇怪。改成**自然流畅的武侠动作**：
- 待机：重心稳、轻微呼吸起伏，持刀手自然。
- 走/跑：腿用 IK 踩实地面、不打滑；手臂与腿反向摆；身体随步伐有自然的上下和前倾；跑步有腾空。
- 劈砍：起手蓄力 → 转腰挥出 → 命中顿一下 → 收势，刀的轨迹和刀光对得上，前脚跟着踏出。
- 受击、死亡（如有）也顺。
- 男女主角都要调。可以用 `prototype/cutout/tune.sh` 的调参面板思路，最后写回 rig.json。
- 出动作检查图：每个动作取 6～8 帧拼一张（`ui-shots-v5/motion-<角色>-<动作>.png`），自己看关节有没有断、动作顺不顺。
