# 男主角改成斗笠少年（交给 Codex）

用户决定：**男主角**改成参考图里那种少年感觉，**女主角（nvjiang 鬼面女将）保持原样，不要动**。

## 目标形象

照 `mobile/art/piying/style-ref.webp` 左边的少年，以及现在的男头像 `mobile/art/ui-icons/portrait.png`（斗笠少年，界面里已在用）：
- 少年，清瘦、灵巧，不是魁梧的武将；脸是皮影侧脸，杏眼、细眉。
- 竹编斗笠（带朱红系带、帽檐镂空），斗笠下露出黑发。
- 朱红长围巾/飘带，在脖子上绕一圈后往身后飘。
- 青绿（翡翠/孔雀绿）短打上衣，镂空云纹，朱红腰带；袖口收紧。
- 深褐/墨黑灯笼裤，绑腿，布靴。
- 拿的还是刀（dao）和剑（jian），兵器部件可沿用现有的，风格对得上就行。
- 皮影质感：透光的染色皮子、镂空花纹、关节铜铆钉。头像、战场人物、创角页、角色信息、行装页里的立绘必须是**同一个人**。

## 怎么做

男主角的皮影部件在 `mobile/prototype/cutout/piying/`（流程见 `mobile/prototype/cutout/README.md`）：
1. 改 `piying/prompts.json` 的 parts 提示词：角色描述换成上面的少年；**部件清单、三行四列的布局、每件的朝向和关节画法保持不变**，
   这样 `cut.py`、`rig.json`、`cutout_rig.gd` 都能沿用。参考图同时传 `style-ref.webp` 和 `ui-icons/portrait.png`。
   斗笠可以画在头部件上（head），飘带用现有的 hair/飘带那一格。
2. 用内置图像工具出 3 张备选，挑最好的切件（`cut.py`），替换 `piying/parts/`（旧图先备份到 `piying/parts-old/`，验收完删掉，不要留在仓库）。
   原图存 `piying/source/`。
3. 按新部件调 `piying/rig.json`（关节点、scale、下摆、握刀），用 `tune.sh` / `compare.py` 或截图确认：
   站姿不驼背、腿脚比例对、刀握在手里、走跑攻击不穿帮。少年比例：大约 6.5 头身，比原来的刀客瘦。
4. 男头像 `ui-icons/portrait.png` 如果和新战场人物对不上，用新部件重拼或重出，保证一致。
5. 顺手修：横屏层主战（`tests/_cutout_battle.gd` 截横屏）主角整个站在层主身后被挡住，看不清。
   让主角画在层主前面，或者错开站位，主角始终看得清。不要改战斗数值规则。
6. 验收：`run_tests.gd`、`run_playthrough.gd` 都 0 失败；截图竖屏挂机、竖屏连战（攻击帧）、横屏层主战、行装、角色信息、创角，
   存到 `mobile/art/piying/ui-shots-v3/`，再拼一张总览 `overview.jpg`。和参考图里的少年对比，像了才算完。
   不要 git commit / push，不要留临时文件。

完成后在本文件末尾追加「完成情况」。

## 完成情况

- 内置图像工具同时使用战斗参考图和现有男头像，三张候选保存在 `mobile/prototype/cutout/piying/source/`。选用第二张，`cut.py` 识别出 12 件。现有头像与新头件的侧脸、黑发和斗笠相符，创角和角色信息继续使用这张头像。
- 按颈、肩、肘、腕、拳心、膝、踝和鞋底重新定位骨骼，并调整帽檐宽度、飘带长度、四肢和衣摆比例。在动作演示里检查了待机、走、跑和劈砍。行装页按男主备战姿势取景，可看到完整刀尖。
- 横屏层主战中主角在层主之后绘制，近身时仍能看到脸和持刀手。截图脚本的第四个参数支持 `boss`，可直接复查单场层主战。
