# 皮影风第四版：照四张界面样稿改（交给 Codex）

用户又给了四张样稿，「按照这个风格样式再修改一版」。样稿存在 `mobile/art/piying/`：

| 文件 | 内容 |
| --- | --- |
| `ref-title.webp` | 标题页 |
| `ref-armory.webp` | 行装（换装）页 |
| `ref-weapons.webp` | 兵器选择 |
| `ref-settings.webp` | 设置页 |

`style-ref.webp`（战斗）和 STYLE-V2.md 的风格要点继续有效；HERO-YOUTH.md 定下的斗笠少年男主角继续有效，女主角不动。
样稿是横屏的，游戏以竖屏 390×844 为主、也支持横屏：**两种朝向都要做好**，竖屏把左右布局改成上下布局。

## 从样稿里读出的共同样式（全游戏统一）

- **底子**：每个页面都铺月夜河景（满月、拱桥灯笼、水面倒影、远山雾、垂柳），**最前面一层暗色芦苇/垂柳剪影**框住画面四边。面板浮在景上，景透出来。
- **页面标题牌**：深红底、金色细边、两头大卷云如意纹的横牌，居中放在页面顶上（「兵器」「设置」「行装」）。标题下可以带一条金色横杆。
- **面板**：深青色（#1f3a3a 左右）半透明底，金色细线框，四角金色卷云；面板里的小格同样是深青底金细框，选中的格子**金橙色发光描边**。
- **小标签**：格子顶上压一块小的深红金边如意牌写名字（「头饰」「衣装」「刀」「剑」）。
- **按钮**：深红底、金边、两头如意卷云、里面有暗红卷草纹的长牌；当前选中的是更亮的朱红并带纹样（设置页左边「声音」）。
- **圆形图标按钮**：深红底金边的圆章（右上角暂停）。头像是左上角金边圆框。
- **滑块**：金色细轨道两头卷云，已填充部分是发光的金色，圆形金色滑钮。
- **数值对比**：变化值用绿色（+8），「24 → 27」这样写；面板竖排在一侧。
- **字**：标题用米白/金色的书法感字体，正文米黄。
- **皮影物件**：装备、兵器图标都是皮影镂空风格的物件图，带透光和铜钉，不是平面图标。

## 逐页要求

1. **标题页**（scripts/title_page.gd）：照 `ref-title.webp`：大号金色书法标题（游戏名**仍然是「吾行」**，不要改成样稿上的字），
   下面一块深红如意牌「进入游戏」；斗笠少年皮影站在河边石头上，拿签子挑着一盏发光的红灯笼，水里有倒影；左上垂柳，四周芦苇。
   标题页主角立绘用新出的整幅皮影图即可（可以出一张专用图）。「试演 · 动作与换装」作为次级按钮保留。
2. **行装页**（scripts/armory.gd、armory_figure.gd、equipment_slot.gd）：照 `ref-armory.webp`：
   - 横屏：左半边是**大幅主角立绘**站在河边（就用游戏里的皮影主角，放大），右边是装备槽面板 + 一侧的属性对比竖条 + 下面背包格 + 底部「换装」按钮。
   - 竖屏：上面是大幅立绘，下面依次是装备槽、属性对比、背包。
   - **装备槽用游戏现有的五个槽（武器、上衣、护腕、护腿、靴子），不要照样稿加头饰、腰饰**。每个槽是一个带小红牌标题的深青金框格子，选中的发金光。
   - 背包格同样式；装备图标改成皮影镂空物件图（现在 forge_art.gd / equipment_slot.gd 用的图标要重出成这种风格）。
3. **兵器页**：照 `ref-weapons.webp`：一根金色横杆上挂着几幅半透明的纱幡（顶上垂红黑相间的流苏和挂饰，两端挂灯笼），每幅纱幡里一件大的皮影兵器，
   顶上小红牌写名字，选中的那幅发金光。**用游戏现有的兵器种类（刀、剑、枪、弓，见 Gear.Rules.NAME_PARTS.weapons），不要加灯笼兵器。**
   游戏里哪里在选兵器种类（锻造页的兵器分类、行装页的兵器筛选、或创角/试演），就把这种挂幡样式用在那里；如果没有合适的地方，
   在锻造页选兵器种类处做成这种样式。底部按钮照样稿（例如「试招」「装配」可换成游戏里实际的操作名）。
4. **设置页**：游戏现在只有一个声音开关（scripts/sound.gd、gothic.gd 的 sound/mute 图标）。照 `ref-settings.webp` 做一个设置面板：
   右上角的声音按钮改成打开设置；左边竖排分类牌「声音」「画面」「操作」，右边是内容：
   - 声音：主音量、音乐、音效三条金色滑块（用 AudioServer 的总线实现；没有对应总线就建，存进存档或 user:// 的设置文件，重启后保留）。
   - 画面：放游戏里已有的画面相关开关（例如倍速、性能显示），没有就只放一项「战斗倍速」。
   - 操作：放已有的操控方式（手动、辅助、全自动）。
   - 底部「恢复默认」「返回」。不要做游戏里根本不存在的功能。
5. **其他页面**（选角、创角、仙班、角色信息、锻造、告示、离线收益、层间过场、渡劫）：套用上面的共同样式，统一标题牌、面板、按钮、格子、背景河景和前景芦苇。
6. **战斗**：修横屏层主战的遮挡：主角现在画在层主后面，身体被盖住大半。让主角**始终画在精怪前面**（或层主近身时错开纵深），主角整身都要看得清。
   竖屏也检查。不要改战斗数值规则。
